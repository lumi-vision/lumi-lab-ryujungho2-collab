## 해석

1. **IRIS 구현과 완전히 같다**: 일반·지속 판정 24/24, 처음 실패 시각도 프레임 단위로 같다. 우리 iris 모드가 IRIS 규칙(1초 전이 4~6, 5초 창 80%)을 정확히 옮겼음을 확인.
2. **IRIS 규칙은 '5초 초과'가 아니다**: 2.5·3 Hz 를 4.5초만 깜빡여도 약 5초 시점에 실패(1초 창 채우는 시간 + 4초 누적). ITU 문구("more than five seconds")를 글자대로 읽은 continuous 모드는 4.5초 깜빡임을 통과시킨다.
3. **빈도 하한**: IRIS 는 2 Hz 미만(1, 1.5 Hz)을 지속 플래시로 보지 않는다. 1~3 Hz 변형은 1 Hz 도 4.5초면 위험으로 본다.
4. **근거 등급**: ITU-R BT.1702 의 지속 플래시 문장은 빈도·창·문턱이 없는 주의 문구다. 숫자는 IRIS(와 Harding FPA 의 '5초 중 80%')의 구현 선택이다.

## 결정 (2026-11-12, 사용자)
- 지속 플래시는 ITU-R 방식(진폭·면적은 기준 이상, 빈도가 1초 기준 아래인 깜빡임이 오래 지속)으로 가고, 구체 숫자는 IRIS 구현을 따른다(`measure.extended_flash`, mode='iris').
- 변형(1~3 Hz, 5초 초과 연속)은 옵션으로 남겨 팀원 판별기와 정의를 맞출 때 비교한다.
- 아직 기본 판정(`analyze` 의 dangerous)에는 넣지 않았다. 넣으면 데이터 라벨에 '지속 위험'이 추가된다(우리 오라클·GAN 클립은 2초라서 5초 창 규칙에 원리상 걸리지 않는다).
