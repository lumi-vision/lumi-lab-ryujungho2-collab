# 학습용 GAN 샘플 — 무효 처리 (2026-11-09)

이전에 여기 기록했던 240개(`gan_v1_div05.pt`, 배율 0.5 → **64×36**)는 오라클 데이터(**128×72**)와 해상도가 달라
탐지 모델 학습에 함께 쓸 수 없어 **삭제했다**. 당시 결과(목표 hazard → 위험 117/120, near → 안전 120/120)는
G 를 학습한 바탕에서 잰 값이었고 일반화 지표도 아니었다.

재발 방지: `scripts/make_gan_dataset.py` 는 이제 G 의 학습 해상도·fps 가 데이터 트랙과 다르거나 배율이 1.0 이 아니면
멈춘다(`--allow-mismatch` 없이는). 같은 트랙(128×72, 24 fps)에서 학습한 G 로 다시 만든다.
