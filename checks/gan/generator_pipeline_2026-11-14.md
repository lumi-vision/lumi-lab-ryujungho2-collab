# 2026-11-14 G 생성 모듈·플레이어 연결 점검

이전 작업의 미커밋 GAN·학습 코드와 생성 메뉴를 보존하고, 생성 모듈과 플레이어의 쌍 저장·의도 표시를 보완했다. 새 학습은 실행하지 않았다.

## 변경

- `generate.make(recipe, out_dir, clean=..., fps=...)`로 임의의 BGR uint8 클립을 넣을 수 있다. 기존 바탕 데이터와 외부 영상 경로도 지원한다.
- 원본·합성본·허용 마스크·실제 변경 마스크를 한 NPZ에 저장한다. 원본 배열 SHA256 및 GAN 체크포인트 SHA256을 레시피에 기록한다.
- 생성 의도를 `hazard_*` 정답으로 기록하던 동작을 제거했다. `intent_hazard`에 따로 저장하고, 판정은 JSON 및 별도 judgement NPZ로 남긴다.
- 플레이어에서 생성 쌍의 둘째 칸은 원본과 실제 변경 영역이다. 생성 의도 일치 여부와 실제 판정 결과를 구분한다. 새 형식을 다시 열어도 이 구분을 유지한다.
- 외부 원본 경로·구간 입력 및 한 프레임씩 이동을 추가했다. 같은 초에 들어온 생성 요청도 작업 ID로 구분하고 기존 NPZ를 덮어쓰지 않는다.
- 잘못된 면적·파형·목표와 Nyquist 주파수 이상 요청을 거부한다.

## 한계와 다음 작업

- 두 GAN 샘플은 연결 동작 확인이며 통계적 성능 평가가 아니다. 기존 체크포인트의 전체 검증 분할 평가가 필요하다.
- 학습된 G는 휘도 전용이다. 적색·줄무늬는 규칙 기반 합성이다.
- `clean`은 합성 전 원본이다. 원본 자체의 안전성, 실제 위험 데이터에 대한 복원 성능, PLAN의 최소 보정 B 정답은 보장하지 않는다.
- 외부 영상은 일정 프레임률 기준이다. 가변 프레임률 타임스탬프 정규화는 구현하지 않았고, 해상도는 비율 유지 축소만 하므로 GAN 학습 규격과 다르면 거부한다.
- 기존 형식의 NPZ에 이미 들어 있는 `hazard_*` 라벨은 자동 변경하지 않는다. 새로 생성해야 v2 의미가 적용된다.
- 전체 판정과 빠른 판정은 줄무늬 경로가 다르다. 학습 라벨로 사용할 때 판정 코드 해시와 모드를 고정해야 한다.
