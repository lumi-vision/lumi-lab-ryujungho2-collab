## 판정 (사전에 정한 규칙: A 가 C 보다 AUC 0.05 이상 높으면 'CorrNet 앞부분을 오탐 게이트로 쓴다')
- **dangerous: A 0.755 vs C 0.678 (+0.077) → 규칙 충족.** flash: A 0.873 vs C 0.717 (+0.156). pattern: 0.622 vs 0.615 (차이 없음, 둘 다 약함).
- 위험 지도 head 를 그대로 쓴 zero-shot(B)은 C 와 비슷(0.655 / 0.710) — 학습한 '특징'은 실제 영상의 깜빡임 정보를 담지만, 합성용 head 는 그대로 쓰기 어렵다.
- 해석: 합성 '층 벗기기'로 학습한 인코더·시공간 어텐션이 실제 영상의 **깜빡임 위험**을 일반 영상 특징(Kinetics)보다 잘 가른다. 패턴은 어느 특징도 약하다 → 패턴은 알고리즘(격자 판정기) 담당이 맞다.
- 한계(공정성): C 는 112×112·16 프레임 묶음(사전학습 규격), A 는 384×216·192 프레임 — 해상도·시간 길이가 달라 C 에 불리할 수 있다. 라벨은 South 사람 라벨(영상 단위·정의 차이). 표본 오류 11 건 제외.
- 다음: 격자 판정기 깜빡임 후보(F1·F2 '후보 모드')에 이 특징 + 로지스틱 회귀를 오탐/놓침 보조로 붙이는 실험(옵션 B), 해상도 맞춘 C 재측정.
