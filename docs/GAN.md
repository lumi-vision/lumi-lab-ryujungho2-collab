# 조건부 GAN — 규칙을 목표로, 자연스럽고 다양한 '빛'을 학습

> 코드: `src/lumi_synth/gan.py` · 학습: `scripts/train_gan.py` · 평가·데이터 저장: `scripts/eval_gan.py` · 결과: `checks/gan/README.md`
> 이전 실험 기록: 보관 브랜치 `archive/2026-11-08-before-reset` 의 `docs/GAN_EXPERIMENTS.md` (E1, E2)

## 1. 오라클과의 관계 — 왜 둘 다 필요한가

| | 오라클 | GAN |
|---|---|---|
| 물리 모델 | X_lin = Y_lin + M·w(t)·δ | X_lin = Y_lin + M·Δ_G(t,p \| Y, M, c, z) |
| 빛의 모양 | 마스크 안 **균일**, 파형은 **정해진 식** | 장면에 맞춰 **공간적으로 퍼지고**, 리듬이 **z 에 따라 다양** |
| 정답 | 판정 규칙 | 같은 판정 규칙 (학습 후 하드 판정으로 다시 잼) |
| 강점 | 조건을 정확히 통제 → 경계 쌍, 평가 기준 | 겉모습 다양성, 문턱 바로 근처 사례를 골라 만들 수 있음 |
| 약점 | 단조로움 → 탐지 모델이 '덮어씌운 티'를 외울 위험 | 규칙의 빈틈을 이용할 위험 → 하드 판정으로 반드시 재확인 |

GAN 은 **판정 기준을 새로 만들지 않는다**. 같은 규칙 아래에서 겉모습을 다양하게 만드는 역할이다. 효과는 "오라클만 vs 오라클+GAN" 으로 탐지 모델을 학습해 **합성하지 않은 실제 영상**에서 비교해야 주장할 수 있다(아직 안 함, §6).

## 2. 이전 실험에서 배운 것과 이번 설계

| 이전 결과 | 이번 대응 |
|---|---|
| **E1**: 오라클 결과를 정답(L1)으로 따라 하게 학습 → '오라클 평균판'으로 붕괴(같은 조건에서 z 를 바꿔도 세기 표준편차 0.0004). Barbu(2020) 구현에서도 같은 현상이 보고됨 | 오라클 재구성 손실 없음. **미분 가능 판정기**가 목표 판정에 맞추게 함 |
| **E2**: 판정 목표로 학습 → 목표 판정 91~99% 조절, 붕괴 해소 | 그대로 계승 |
| **E2a**: RGB 잔차 출력 → 질감 절반가량 손실 | 출력 = **빛의 양 Δ ≥ 0 한 채널, 1/4 해상도** → 원본 윤곽선이 그대로 남고 빛은 부드럽게 퍼짐 |
| **E2b**: 픽셀 L1 다양성 손실 → 주파수 대신 진폭만 다양 | 다양성 손실을 **빛의 시간 스펙트럼** 차이로 (E2c 로 계획했던 것) |

## 3. 미분 가능 판정기 (soft judge)

하드 판정의 각 단계를 시그모이드로 완화해 기울기가 흐르게 했다.

| 하드 판정 | 소프트 근사 | 차이 |
|---|---|---|
| 픽셀 전이: 직전 극값 대비 ≥ 20 cd/m² (히스테리시스) | 1~c 프레임 전 대비 변화의 큰 쪽, σ((ΔL−20)/τ) | c 프레임보다 느린 변화는 덜 센다 |
| 어두운 쪽 < 160 | σ((160 − min)/τ) | — |
| 방향별 면적 > 25% | σ((A − 0.25)/τ_a) | — |
| 상태 기계(같은 방향 연속 1번) | '직전 프레임에 같은 방향 후보가 없을 때' 새 전이 | 긴 간격을 둔 같은 방향 반복은 더 센다 |
| 두 방향 동시 후보 1번(D4) | 두 방향의 새 전이 중 큰 값만 | — (v1 에서 맞춤) |
| 1초 창 최대 | 이동 합 후 최댓값(amax, 부분 기울기) | — (v1 에서 맞춤) |

**버전 기록**: v0 은 반대 위상 깜빡임을 2번으로 세고(2 Hz 안전 영상 → 8.8, 위험 목표 충족) log-sum-exp 로 약 +0.8 과대였다. 독립 리뷰(2026-11-09)에서 발견해 v1 에서 고쳤다(`SOFT_JUDGE_VERSION`, 테스트 `test_soft_judge_counts_opposite_phase_once`). 체크포인트에 학습 때 쓴 버전을 기록한다.

남은 차이가 있으므로 **학습 후 모든 출력은 하드 판정으로 다시 잰다**. 두 판정의 일치도(상관, 위험/안전 일치율)를 `checks/gan/README.md` 에 기록한다. 단순한 화면 깜빡임에서 둘의 차이가 전이 1번 이내임을 테스트로 고정했다(`test_soft_judge_tracks_hard_judge_on_simple_flicker`).

## 4. 학습 한 스텝

```
바탕 Y (깨끗한 클립) ──┐
마스크 M (오라클 생성기, 면적 0.32~0.70, 10% 는 화면 전체) ──┤
목표 c (위험 / 문턱 근처 안전, 반반) ──┼─► G ─► 빛 Δ (1/4 해상도 → 확대) ─► X = sRGB(Y_lin + M·Δ)
잡음 z1, z2 ──────────────────────┘                                      │
                                                                         ├─► 소프트 판정 ─► 판정 손실 (위험: 전이 ≥ 8, 근처: 2~5)
                                                                         ├─► D(프레임 한 장) ─► 적대 손실 (진짜 = 깨끗한 바탕 프레임)
                                       Δ(z1), Δ(z2) 의 시간 스펙트럼 차이 ─► 다양성 손실
손실_G = 1.0·판정 + 0.1·적대 + 0.05·다양성
```

- **문턱 근처 안전 목표**(전이 2~5번 = 깜빡임 1~2.5번/초, 면적은 25% 초과): 위험과 조건 하나(횟수)만 다른 **가장 어려운 음성 사례**. 무작위 오라클로는 드물게 나오는 사례를 골라 만들 수 있다는 것이 GAN 의 실질적 이점이다(E2 에서 무작위 오라클은 10~13% 만 '근처'였다).
- **D 는 프레임 한 장만** 본다: 깜빡임 자체는 벌주지 않고, 빛 번짐이 어색한지(네모 덩어리 등)만 본다.
- **마스크 밖은 구조적으로 원본과 같다**(M 을 곱함) → 국소성 손실이 필요 없다(`test_gan_locality_and_shapes`).

## 5. 평가 (검증 분할만, 하드 판정으로)

1. 조절력: 목표 '위험' → 실제 위험 비율, 목표 '근처' → 안전이면서 1~3회/초 비율
2. 대리 판정 신뢰도: 소프트 ↔ 하드 전이 수 상관, 위험 판정 일치율
3. 다양성: 같은 (Y, M, c) 에서 z 만 바꿨을 때 깜빡임 수·주 주파수의 표준편차
4. 국소성: 마스크 밖 바뀐 값의 개수 (0)
5. 대조군: 같은 구조의 학습하지 않은 G

시험 분할(Elephants Dream)은 쓰지 않는다 — 탐지 모델 최종 평가용으로 남긴다.

`data/gan/val/` 샘플은 **평가 전용**(`purpose: evaluation_only`)이다. 탐지 모델 학습용 GAN 샘플은 train 바탕으로 따로 만들어야 한다(아직 스크립트 없음). 그렇지 않으면 val 누수로 H1 비교가 불공정해진다.

## 6. 하지 않은 것 (주장하지 않음)

- 자연스러움의 정량 평가(사람 평가, 실제 영상과의 분포 거리): 없음
- 노트북 학습은 64×36, 500스텝의 **동작 확인**이다. 본 학습은 집 PC(RTX 5080)에서 128×72 이상, 수천 스텝으로 한다
- 탐지 모델을 학습해 "오라클 vs 오라클+GAN" 을 비교하는 실험(H1): 아직 안 함
- 적색 깜빡임·패턴: 범위 밖

## 7. 첫 실측 결과와 해석 (2026-11-09, 노트북 CPU, `checks/gan/README.md`)

조건: 64×36, 500스텝, 배치 4, 소프트 판정기 **v0**(리뷰 전) 로 학습. 검증 바탕 12개 × 목표 2종 × z 4개, 하드 판정으로 측정.

| 지표 | 학습한 G | 학습 안 한 G |
|---|---|---|
| 목표 '위험' → 실제 위험 | 47/48 (98%) | 10/48 (21%) |
| 목표 '근처 안전' → 안전 & 1~3회/초 | 44/48 (92%) | 23/48 (48%) |
| 소프트↔하드 전이 수 상관 / 위험 판정 일치 | 0.99 / 97% | 0.89 / 88% |
| z 만 바꿨을 때 주 주파수 표준편차 | **0.38 Hz** | 2.87 Hz |
| 마스크 밖 바뀐 값 | 0 | 0 |

- **조절력은 학습으로 생겼다**: 대조군 대비 위험 목표 21% → 98%, 문턱 근처 목표 48% → 92%.
- **다양성은 학습으로 줄었다 (부분 모드 붕괴)**: 같은 조건에서 z 를 바꿔도 리듬이 거의 같다. 판정 손실(가중치 1.0)이 0 근처로 빨리 내려간 뒤 다양성 손실(가중치 0.05)이 너무 약해 z 를 무시하는 쪽으로 수렴한 것으로 보인다(추정, 미검증).
- 다음 실험(미실행): λ_div 를 0.05 → 0.5·1.0 으로 올려 조절력과 다양성의 교환 관계를 측정, 소프트 판정기 v1 로 다시 학습, 집 PC 에서 128×72·수천 스텝.
