# GAN 생성과 전용 검사 플레이어 (2026-11-14)

사용 흐름: **원본 폴더 → 원본 선택 → GAN 합성 → MKV·NPZ 저장 → 검사 플레이어 → 탐지 결과**.

## 담당 파일

| 역할 | 파일 |
|---|---|
| 생성 화면 | `scripts/static/generator.html`, `LUMI_생성기.bat` |
| 폴더 메타데이터·무손실 출력·완료 결과 목록 | `src/lumi_synth/generation_workspace.py` |
| G 추론과 원본·합성본 쌍 | `src/lumi_synth/generate.py` |
| 서버·검사 플레이어 | `scripts/make_playlist.py`, `LUMI_플레이어.bat` |

## 서버 경로

- `GET /generate`: 독립 생성 화면.
- `POST /api/sources`: 지정 폴더 영상 목록 및 해상도·fps·길이. 깨진 파일은 해당 행에 오류 표시.
- `POST /api/generate`, `generation_only: true`: 기존 생성기를 사용하되 탐지·비교 영상 생성을 생략. 쌍 데이터, 픽셀 보존 FFV1 MKV 및 완료 JSON을 저장.
- `GET /api/generated`: 완료 기록을 디스크에서 읽어 표시. 생성 결과는 아직 판정하지 않은 것으로 취급.
- `GET /?inspect=<id>` → `POST /api/inspect`: 해당 NPZ의 원본·합성본을 각각 기존 검사 작업 큐에 넣는다. 결과 ID는 생성 폴더 안에서만 찾는다.

생성 화면은 학습된 GAN만 제공한다. 위험 종류는 체크포인트의 `config.hazard`에 따르며, 기존 기록 없는 체크포인트는 휘도용이다. 규칙 합성은 기존 플레이어의 고급 실험 메뉴에 유지한다. 생성 화면의 여러 원본 요청은 같은 서버 큐에서 순서대로 실행한다.

## 확인

- 무손실 출력 왕복에서 원본 배열과 FFV1 디코드 배열이 픽셀 단위로 일치한다.
- HTTP 통합 테스트: 폴더 조회 → 생성 전용 요청 → MKV·NPZ·완료 기록 저장 → 판정 캐시가 아직 없음 → 명시적 검사 → 원본·합성본 두 결과와 판정 캐시 생성.
- 실제 브라우저: 폴더 목록 표시, 해상도·fps 표시, 학습 규격 불일치 요청 거부, 생성/검사 화면 이동 확인.
- 검사 중 발견한 OpenCV 5의 `putText` 8비트 입력 요구에 맞춰 'NO LABEL' 등 안내 패널을 uint8로 변환했다.

이 작업에서는 G를 새로 학습하거나 실행 중인 별도 학습 프로세스를 변경하지 않았다. 현재 외부 원본은 일정 프레임률 SDR 구간 입력이며, 전체 장편 영상 처리·프레임률 정규화·최소 보정 정답 생성은 별도 작업이다.
