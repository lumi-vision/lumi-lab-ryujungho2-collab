# 머신러닝을 어디에 · 왜 쓰는가 (2026-11-25)

> 원칙: **정답이 규격·의학 문헌에 있는 것은 규칙으로, 정답이 사람의 지각에 있는 것은 사람 데이터로 학습한다.**
> 학습으로 규격·의학 문턱(예: 패턴 cpd 하한)을 '찾았다'고 말하지 않는다 — 우리 데이터에는 발작·뇌파 라벨이 없어서 학습이 찾는 것은 '사람의 지각 경계'뿐이다.

## 전체 구조
```
영상 ─▶ [1층 규칙 G: 픽셀 측정 → 격자 근거]  ──▶ 규격 판정(BT.1702 축 · Fisher 2026 축) + 근거 문장·그림   ← ML 없음
            │ 규칙의 여유값(margin)·격자 FFT·cpd 위험 가중
            ▼
        [2층 ML ①: 위험 점수]  ──▶ 사람이 느끼는 위험의 순위·문턱 근처 판단 보조
            │ 위험 영역·시점(1층 지도)
            ▼
        [보정: 그 영역만 감광]  ──(파라미터 후보)──▶ [1층으로 재판정 = 안전 제약, 반드시 통과]
                                         └─▶ [ML ②: 자연스러움 모델] 이 고른 가장 자연스러운 후보 출력
```

## 1층 — 규칙 (ML 을 쓰지 않는 곳과 이유)
| 결정 | 근거 | 왜 ML 이 아닌가 |
|---|---|---|
| 깜빡임 20 cd/m²·25 %·초당 3 회, 적색, 연장 | ITU-R BT.1702-3, Ofcom, IRIS | 규격 문구가 정답. 학습하면 규격 준수를 증명할 수 없음 |
| 패턴 쌍 > 5·면적 40/25 %·흐름 면제 | BT.1702-3 Att.1 | 같음 |
| 패턴 cpd 대역 | BT.1702 축: 없음 · Fisher 2026 축: 1–8 cpd (Wilkins 1979) | 의학 문턱(환자 비율)은 뇌파 연구가 정답. 우리 데이터로는 못 찾음 |

## 2층 ML ① — 위험 점수 (실험 완료: `docs/PREREG_FFT_RULES_ML_2026-11-24.md`)
- **무엇을**: 1 층 규칙의 여유값 + 격자 칸 temporal FFT (+ 예정: Wilkins cpd 곡선 가중) → 로지스틱 회귀(계수 몇 십 개).
- **왜**: 규칙은 예/아니오라서 문턱 바로 아래(초당 2.9 회, 면적 24 %)와 완전히 안전한 것을 구별하지 못한다. 사람은 문턱 아래도 '깜빡인다'고 느낀다(South 사람 라벨).
- **결과**: 사람 '깜빡임' 판단 AUC — 규칙 그대로 0.780 → 학습 가중 0.967 (사전 기준 충족). CorrNet 특징은 더해 주는 것 없음.
- **한계**: South 한 데이터셋 내부. 외부(Kaya·FlashGuard)·출처 교차 검증 필요.

## ML ② — 감광 보정의 자연스러움 (계획 — 아래 사전 등록 후 진행)
### 왜 여기에 ML 인가
안전은 1 층이 정확히 판정할 수 있지만, **"얼마나 자연스러운가"는 규격에 없고 사람의 지각이 정답**이다. 같은 안전 수준에서 감광 세기·영역 가장자리 흐림·시간 램프가 달라지면 자연스러움이 달라지고, 그 관계는 사람 평가로만 잴 수 있다.

### 설계
1. **보정 후보(규칙 기반, 학습 없음)**: 1 층 지도의 위험 칸만 감광. 파라미터 θ = (감광 세기 k, 가장자리 흐림 폭, 시간 램프 길이, 칸 대신 픽셀 마스크 여부, 색 유지 여부).
2. **안전 제약(하드)**: 모든 후보를 1 층으로 재판정 → 통과한 것만 남김. 자연스러움이 아무리 높아도 위험이 남으면 탈락.
3. **사람 평가**: 같은 클립의 두 후보를 나란히(블라인드, 순서 무작위) — "어느 쪽이 더 자연스러운가(원본과 가까운가)". ⚠️ 평가자 안전: 평가 영상은 **보정 후(1 층 통과)** 만 보여 주고, 원본 위험 영상은 정지 프레임으로만.
4. **ML ②**: 쌍 비교 → Bradley–Terry(또는 로지스틱) 모델로 '자연스러움 점수 = f(θ, 영상 특징)'를 학습. 객관 지표(LPIPS·위험 밖 PSNR·변경 픽셀 비율·시간 흔들림)를 특징으로 넣어, **객관 지표가 사람 판단을 얼마나 대신할 수 있는지**도 함께 보인다.
5. **사용**: 새 영상에서는 안전 제약을 통과한 후보 중 ML ② 점수가 가장 높은 θ 를 고른다(가중치를 사람이 손으로 정하지 않음).
6. **검증(사전 등록)**: 학습에 쓰지 않은 클립에서 ML ② 가 고른 θ vs 고정 θ(전체 감광, FlashGuard 식) 블라인드 선호 > 50 % (이항 검정), 안전 통과율 100 % 유지. — `docs/BENCHMARK_FLASHGUARD_KAYA.md` 의 '블라인드 선호' 기준과 같은 틀.

### 주의
- 평가자 수·클립 수가 작으면 개선을 주장하지 않는다(신뢰구간 보고).
- 자연스러움 모델이 '위험을 덜 지우는 쪽'을 선호하는 것은 안전 제약이 막는다 — 이 분리가 이 설계의 핵심 논리다.
