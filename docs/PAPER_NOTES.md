## A. 직접 선행 연구

### A1. Barbu, Banda & Katz (2020) — 접근성을 위한 영상→영상 변환 [원문]
*Pattern Recognition Letters* 137:99–107, doi:10.1016/j.patrec.2019.01.019

- **무엇을 했나:** 위험 자극을 "넣는" Forward(수작업 Oracle 또는 GAN)로 원본–변형본 쌍을 만들고, 이를 되돌리는 Inverse(보정 모델)를 학습했다. 보정 모델은 세 가지(Bi-ConvLSTM, ConvLSTM U-Net, STA)를 비교했다. 데이터는 YouTube 원본 2만 개, 64×64·100프레임 클립 20만 개, 시험용 원본 2,000개(원본 단위 분리).
- **핵심 결과:**
  - 사람 평가(Table 2): 변형본이 더 깜빡인다고 고른 비율 Oracle 91%, GAN 83%.
  - 보정(Table 3, Oracle+GAN 1:1 혼합 데이터): 깜빡임 감소로 선택된 비율 LSTM 81.8%, U-Net 76.8%, STA 74.2%. 원본 입력에서는 우연 수준(영상 보존).
  - 시간 정보 제거 실험: 단일 프레임으로 줄이면 사람들이 전체 모델을 94.4% 선호.
  - 객관적 지표는 없고 모든 정량 결과가 사람 선호도. Oracle-only 대 Oracle+GAN 비교는 없음.
- **인사이트:**
  - 논문의 진짜 기여는 GAN이 아니라 "**정확한 변형을 지정하지 않고 Forward 합성으로 보정기를 학습한다**"는 틀이다.
  - GAN이 Oracle보다 나은지는 이 논문으로 알 수 없다. 이 빈칸이 바로 우리 H1이다.
  - 보정 성능은 시간 문맥에 크게 의존한다.
- **LUMI에서 할 수 있는 것:**
  - Forward/Inverse 틀과 "임계값 위·아래를 모두 생성" 원칙을 그대로 쓴다(이미 Oracle에 반영).
  - H1을 Barbu가 하지 않은 **대조 실험**(Oracle-only 대 Oracle+GAN, 샘플 수·학습량 동일)으로 설계하면 기여가 된다.
  - 원본 단위 분할은 이미 구현했다(`split_for_source`).

### A2. Banda (2018) — 위 연구의 구현자 학위논문 [원문]
MIT M.Eng. thesis, DSpace 1721.1/121622 (79쪽)

- **무엇을 했나:** Barbu 2020의 구현 상세. 데이터 수집, Oracle 분포, 검출 네트워크(D), 미분 가능 규칙 검출기(R), 보정 모델, 손실, Forward cGAN, 사람 평가.
- **핵심 결과:**
  - **Forward cGAN은 Oracle 결과를 목표로 학습했다.** 조건 Z = Oracle 파라미터(유형·지속시간·주파수, 세기는 없음), Z에서 64차원 잠재를 KL 정규화로 샘플링. 저자: "**학습된 모델은 매우 결정적이었다.**" 약한 깜빡임을 더 세고 빠르게 키우는 경향.
  - R(학위논문은 "oracle"이라 부름): 검출 규칙을 텐서 연산으로 옮긴 **학습 파라미터 없는** 검출기. 휘도는 프레임 차 > 20을 30프레임 창으로 셈, 적색은 R/(R+G+B) > 0.8 영역의 변화. 계수 0.299/0.587/0.114(BT.601 luma, W3C 상대 휘도 아님). 저자 경고: "R만 쓰면 G가 어둡게 만들거나 쓰레기로 R을 속인다."
  - D: 시간 분산 합성곱 3층 + LSTM 512×2, 합성 데이터로 미리 학습.
  - 손실 `α·MSE + β·D + γ·VGG + ζ·R`, 실제로는 대개 둘만 켬. `ζ·R`을 넣으면 깜빡임 영역을 흐리게 만드는 법을 빨리 배움. 적대 학습은 끝까지 불안정.
  - 데이터: YouTube 2만 개, **최저 화질**, 30fps, 64×64·100프레임(3.3초), [-1,1] 정규화. Oracle 깜빡임은 **화면 전체**, 1–3초, 저주파 1–3 Hz(음성 사례)와 고주파 약 20 Hz, 유형 4가지(빨강-파랑, 흑백, HSV, 파장 이동). **패턴 생성은 없다.** Oracle 결과 20개는 PEAT와 모두 일치.
  - 보정 쪽 교훈: MSE는 "평균으로의 회귀"(흐리기·어두운 안개)와 "항등으로의 회귀"를 일으킨다. 곱셈형 출력 `tanh(G(x))⊗x`가 덧셈 잔차보다 학습이 빨랐다.
- **인사이트:**
  - **E1의 모드 붕괴는 Barbu 구현에서도 이미 보고된 현상이다.** Barbu는 해결하지 않았다. "Barbu처럼 하면 다양한 G가 나온다"는 근거는 없다.
  - Barbu GAN이 Oracle과 "달라 보인" 이유는 다양성이 아니라 **Oracle 결과를 과장하는 방향의 결정적 변형**이었을 가능성이 크다.
  - R은 결국 Oracle과 같은 규칙에서 나왔다. 정보량을 늘리려면 R의 출처가 달라야 한다(→ B·C·D 절).
- **LUMI에서 할 수 있는 것:**
  - **G:** cVAE식 KL만으로는 붕괴를 막지 못한다는 반례로 쓴다. 전역 잠재 z + 다양성 손실(mode-seeking 등)이 필요하다.
  - **R:** "학습 파라미터 없는 규칙 기반 미분 검출기"라는 형식을 그대로 쓰되, 계수는 문헌 원 곡선으로 바꾼다(BT.601 luma 대신 sRGB 선형화 + 상대 휘도).
  - **손실 설계:** R은 단독으로 쓰지 않고 D와 원본 보존 조건을 함께 건다. Barbu의 실패(흐리기 학습)를 시험 항목으로 만든다.
  - **보정 쪽(팀원·후속):** MSE 회귀 문제와 곱셈형 출력 교훈을 팀원과 공유한다.

## B. 패턴

### B1. Wilkins, Darby & Binnie (1979) — 패턴 민감 뇌전증의 시각 매개변수 [원문]
*Brain* 102:1–25, doi:10.1093/brain/102.1.1 (함께 본 자료: Wilkins 1995 *Visual Stress* 2장 [모노])

- **무엇을 했나:** 패턴 민감 환자에게 줄무늬의 공간 주파수, 대비, 색, 방향, 크기, 양안 조건을 하나씩 바꿔 PPR을 측정한 연구 9개.
- **핵심 결과:**
  - 공간 주파수: 8명 전원 최적 **1–4 c/deg**. 집단 평균 0.5 c/deg 약 0.05, 2–4 c/deg 약 0.8, 8 c/deg 약 0.25.
  - 대비: 0.2→0.4에서 급상승(예: 0/5, 2/16, 9/13, 13/14), 0.3 이상에서 포화.
  - 색: **등휘도 적/녹 줄무늬는 7명 모두 PPR 0.**
  - 방향: 절대 방향은 무관. 그러나 **직교 격자는 단일 방향보다 위험이 낮다**(42–54% → 19%).
  - 크기: 시각 크기 2배로 확률이 0→1. 문턱 반지름은 환자마다 1.5–25°.
  - 양안 융합 줄무늬가 경쟁 줄무늬보다 유발적.
- **인사이트:**
  - 위험의 본질 변수는 "줄 개수"가 아니라 **공간 주파수(c/deg), 휘도 대비, 시각 면적, 방향 집중도**다.
  - 색 대비만으로는 패턴 위험이 생기지 않는다.
- **LUMI에서 할 수 있는 것:**
  - **Oracle:** 패턴 합성을 c/deg·대비·면적·방향 집중도 축으로 다시 매개변수화해, 이 축들의 경계 사례(예: 0.5 c/deg 대 3 c/deg, 대비 0.15 대 0.4, 단일 방향 대 격자)를 의도적으로 생성한다.
  - **R(후순위):** 패턴 경로의 요인 곡선 근거.
  - **G:** 패턴 변형을 생성할 때 "같은 줄 개수라도 c/deg가 다르면 위험이 다르다"는 조건을 줄 수 있다.

### B2. Wilkins, Emmett & Harding (2005) — 발작을 일으키는 패턴의 특성과 지침 최적화 [원문]
*Epilepsia* 46:1212–1218, doi:10.1111/j.1528-1167.2005.01405.x (저자 원고 https://visualstress.info/2005-169.pdf)

- **무엇을 했나:** 기존 환자 자료에 요인별 곡선을 맞추고, 이를 곱한 위험 모델로 영국 ITC 패턴 규칙을 사후 평가·개정 제안.
- **핵심 결과:**
  - 요인별 식: 공간 주파수 3차식(로그 밑 미표기), 평균 휘도 `y = 0.336 ln L − 0.745`(9명), 피질 면적 `y = 0.021Q − 0.184`(19명, 피질 8% 미만 무반응).
  - 변하는 패턴은 정지의 **약 2배** 위험.
  - "5쌍 초과"·"정지 40%"는 "모델에서 개발되지 않고 **임시방편으로 진화**". 50 cd/m²는 모델의 곡선 수렴점. 0.5초는 실험값이 아니라 경험(잠복기 1–2초).
  - 개정 제안: 가장 밝은 줄 > 50 cd/m²이고 0.5초 넘게 지속될 때, 변화 5쌍 / 정지 8쌍 / 흐름 12쌍.
  - 저자: "요인 독립 가정은 **거의 확실히 틀렸다**"(최악 경우 추정).
  - "직교 방향 에너지를 더하면 유발성이 오히려 감소."
  - 원고 오류: 159/179 cd/m²를 "대비 0.34"로 기재(실제 0.059).
- **인사이트:**
  - 가이드라인 패턴 수치는 **특정 TV 시청 조건(20인치, 화면 높이 7배 거리)에 묶인 대리 변수**다. 화면과 거리가 바뀌면 의미가 달라진다.
  - 이미 **미분 가능하게 옮기기 쉬운 곱셈 모델**이 있다.
- **LUMI에서 할 수 있는 것:**
  - **R(패턴):** 출발 모델. 다만 "최악 경우 추정"으로 표시하고, 요인 독립 가정의 한계를 문서에 남긴다.
  - **R·평가:** 시청 기하(화면 크기·거리)와 최대 밝기를 R의 명시적 입력으로 둔다.
  - **Oracle:** "가이드라인은 통과하지만 모델 위험은 높은" 사례(예: 5쌍 이하·3 c/deg·큰 시야각)를 생성해 R과 IRIS가 갈리는 지점을 만든다.

### B3. Binnie, Findlay & Wilkins (1985) — 줄무늬의 움직임과 광발작반응 [원문]
*EEG Clin Neurophysiol* 61:1–6, doi:10.1016/0013-4694(85)91065-x

- **무엇을 했나:** 패턴 민감 환자 10명에게 2 c/deg 줄무늬를 진동(5/10/15/20 Hz), 같은 각속도의 한 방향 흐름, 정지로 보여 줌. 화면 깜빡임을 배제한 회전 드럼 실험(2명) 추가.
- **핵심 결과:** 진동 0 / 0.4 / **0.97** / 0.5, 정지 0.38, 흐름 0–0.04. 위상 반전도 진동과 비슷(10–20 Hz), 40 Hz에서는 둘 다 0. 속도를 맞췄는데 진동과 흐름이 정반대.
- **인사이트:** 위험을 가르는 것은 속도가 아니라 **방향·위상이 바뀌는 시간 주파수**다. 뉴런 집단의 동기화가 핵심.
- **LUMI에서 할 수 있는 것:**
  - **Oracle:** 패턴 시간 변화를 "진동 / 위상 반전 / 한 방향 흐름"으로 나눠 생성한다. 현재 Oracle의 패턴 이동은 이 구분이 없다.
  - **R:** 운동 유형 계수(진동·반전 약 2배, 흐름 약 0.1배)의 근거.
  - **평가:** 같은 줄무늬를 흐르게 했을 때와 진동시켰을 때 R이 반대 판정을 내는지 시험한다.

### B4. Stefánsson 외 (1977) — 정지 패턴과 진동 패턴의 민감도 [원문]
*BMJ* 2:88–90, doi:10.1136/bmj.2.6079.88

- **무엇을 했나:** IPS 민감 환자 32명에게 정지·진동 패턴 검사.
- **핵심 결과:** 23명(72%) 패턴 민감. 진동 22명, 정지 11명 → 진동이 민감도 발생률을 "사실상 두 배".
- **인사이트:** 광과민 환자의 상당수가 패턴에도 민감하다. 깜빡임만 보는 검출기는 일부를 놓친다(B2·Brinciotti·Radhakrishnan과 함께 보면 패턴만 민감한 환자도 11–16%).
- **LUMI에서 할 수 있는 것:** 패턴 경로를 장기적으로 버릴 수 없다는 근거. 지금은 깜빡임 우선으로 가더라도 데이터 규약에 패턴 유형을 유지한다.

## C. 휘도 깜빡임

### C1. Binnie, Emmett, Gardiner, Harding, Harrison & Wilkins (2002) — TV 깜빡임 영상의 특성 [원문]
*SMPTE Journal* 111(6/7):323–329, doi:10.5594/J15330 (스캔 https://visualstress.info/2001-150.pdf)

- **무엇을 했나:** ITC·Ofcom·ITU 깜빡임 규칙의 근거 모델. 위험 = 주파수 × 변조 깊이 × 평균 휘도 × 면적. 방송 녹화로 오경보율 분석.
- **핵심 결과:**
  - 주파수(Jeavons & Harding 170명, 스트로보): 3 Hz 3%, 10 Hz 약 65%, **16 Hz 89%(정점)**, 30 Hz 72%, 50 Hz 49%, 65 Hz 4–5%. 두 번째 곡선(Kasteleijn-Nolst Trenité 1989)은 20 Hz 정점 약 93%, 50 Hz 약 11%.
  - **주파수만 실제 깜빡임으로 측정.** 변조 깊이는 1 Hz 위상 반전 줄무늬(13명), 평균 휘도는 정지 줄무늬("깜빡임 자료 없음"), 면적은 줄무늬(19명).
  - 20 cd/m²와 160 cd/m²는 영화관 밝기 경험, BT.500 기준 밝기, 줄무늬 곡선을 조합해 정함. "4회 이상·대비 20% 초과·화면 1/4 초과"는 방송 3시간의 **오경보 수**로 정함.
  - 20 cd/m² 미만 변화에도 최대 반응자의 7%는 위험. 잔여 위험 약 0.1%.
  - 그림 4는 그림 2×3으로 재현되지 않음(대비 정의 미기재).
- **인사이트:**
  - 가이드라인 깜빡임 규칙 중 **환자 깜빡임 실측에 근거한 것은 주파수 곡선뿐**이다. 나머지는 정책·오경보 기준이다.
  - 주파수 곡선은 계단(3 Hz)이 아니라 **연속 곡선**이고, 정점은 16–20 Hz다.
- **LUMI에서 할 수 있는 것:**
  - **최소 R(우선):** 주파수 가중을 이 원 곡선으로 만든다(1–30 Hz는 두 곡선이 일치해 견고). 30 fps 영상은 최대 15 Hz, 60 fps는 30 Hz까지라 일반 영상은 견고한 구간에 들어간다.
  - **Oracle:** 깜빡임 주파수를 "3 Hz 위/아래" 이진이 아니라 곡선을 따라 고르게 생성하고, 특히 8–20 Hz 구간을 충분히 넣는다.
  - **평가:** IRIS(3회/초 계단)와 R(연속 곡선)이 갈리는 사례(예: 2.5 Hz 대 4 Hz 대 12 Hz)를 비교 항목으로 둔다.

### C2. Wilkins, Binnie & Darby (1980) — 시각 유발 발작 리뷰 [원문]
*Progress in Neurobiology* 15:85–117 (https://visualstress.info/1980-20.pdf)

- **무엇을 했나:** 당시까지의 시각 유발 발작 연구를 종합. Jeavons & Harding 하위 52명 곡선, 개인 곡선, 대비 자료 수록.
- **핵심 결과:** 눈 뜸 20 Hz 약 89%, 감은 눈꺼풀을 통한 자극은 약 52%. 한 환자는 40–50 Hz에서 약 1.0. 광과민 범위 상한이 15–55 Hz 이상으로 넓게 퍼짐. "간헐광의 평균 휘도·duty cycle·변조 깊이를 독립적으로 조사한 연구는 없다."
- **인사이트:** 개인차가 매우 크다. 집단 곡선은 평균일 뿐이며, 깜빡임의 휘도·파형 효과는 1980년부터 지금까지 빈칸이다.
- **LUMI에서 할 수 있는 것:** R 출력을 "집단 추정치"로만 해석하는 근거. 고주파 쪽을 0으로 자르지 않고 보수적으로 남겨 둘 근거(개인 곡선).

### C3. Binnie 외 (1981) — 방 조명, 눈 감음, TV 시청 거리 [원문]
*Advances in Epileptology* pp. 269–273 (https://visualstress.info/1981-25.pdf)

- **무엇을 했나:** 연속 23명을 밝은 방(약 3,400 lux)과 어두운 방(약 20 lux)에서 IPS 검사. TV 민감 16명을 거리별로 검사.
- **핵심 결과:** 방 조명 차이 없음. 눈 감음이 더 민감(15→19명). TV를 1 m 이하에서 본 14명은 전원 **밝은 방에서** 방전 증가. 1 m 넘는 거리의 민감성은 50 Hz 민감 환자에게만 있었다.
- **인사이트:** 근거리 TV 민감성은 주사선 패턴이, 원거리 민감성은 50 Hz 화면 깜빡임이 주도한다. "어두운 방이 더 위험"은 일반화할 수 없다.
- **LUMI에서 할 수 있는 것:** R에 방 조명 보정을 넣지 않는다. 대신 **시청 거리(→시야각)**는 반드시 입력으로 둔다.

### C4. Smedley, Webb & Wilkins (2010) — 면적 함수 [원문]
*Epilepsia* 51:1146–1151, doi:10.1111/j.1528-1167.2009.02402.x

- **무엇을 했나:** 피질 확대 공식을 반각 φ로 쓴 면적 위험식 제시, 깜빡임 대비 문턱 논의.
- **핵심 결과:** `p = −0.184 + 2.11(1 − e^(−0.0574φ))`, φ < 1.6°에서 위험 환자 없음. 깜빡임 대비 문턱 Michelson 5–10%로 제시했으나 근거는 줄무늬 자료(C1).
- **인사이트:** 면적은 화면 비율이 아니라 **시각도**로 계산해야 한다. 같은 "화면 25%"가 TV에서는 위험 약 0.11, 모니터에서는 약 0.62(조사 계산, J&V 2024와 일치).
- **LUMI에서 할 수 있는 것:** **R:** 면적 항을 시각도 기반으로. **Oracle:** ROI 크기를 "화면 비율"이 아니라 가정한 시청 조건에서의 시각도로도 기록한다.

## D. 색 깜빡임

### D1. Parra, Lopes da Silva, Stroink & Kalitzin (2007) — 색과 광과민성 [원문]
*Brain* 130:1679–1689, doi:10.1093/brain/awm103

- **무엇을 했나:** 특발성 광과민성 뇌전증 43명에게 180° 확산 LED로 단색·색 교대 깜빡임을 변조 깊이 25–100%, 10–30 Hz로 보여 줌.
- **핵심 결과:**
  - 색 민감 25명(58%). 반응: 빨강↔파랑 **25명(100%)**, 빨강 22, 빨강↔초록 20, 파랑 18, 흰색 17, 파랑↔노랑 17, 초록 16, 노랑 15, 파랑↔초록 **7(28%)**.
  - 색 교대 PPR의 67–86%가 **10–15 Hz**, 20 Hz 위에서 대부분 사라짐. 단색·흰색은 **20–30 Hz** 정점.
  - 빨강 PPR의 35%가 변조 25–50%(흰색 12%).
  - **두 기전:** 단색 민감도는 흰빛 민감도를 따르고, 색 교대 민감도는 단색과 무관.
  - 색좌표·cd/m²는 미기재. 내부 불일치 몇 군데.
- **인사이트:**
  - 색 깜빡임은 휘도 깜빡임과 **다른 경로**이고 **다른 주파수 대역**에서 강하다.
  - "빨강"보다 **색 쌍**이 중요하고, 빨강은 약한 변조에서도 위험하다.
- **LUMI에서 할 수 있는 것:**
  - **최소 R(우선):** 색 경로를 휘도 경로와 따로 두고, 색 교대에는 10–15 Hz 중심 가중, 색 쌍별 상대 위험을 넣는다.
  - **Oracle:** 현재 `red` 유형은 "빨강으로 섞기" 하나뿐이다. **색 쌍 교대(빨강↔파랑, 빨강↔초록, 파랑↔초록 등)와 등휘도 교대**를 유형으로 추가하면, 파랑↔초록처럼 "색도는 크게 달라도 약한" 음성 사례까지 만들 수 있다.
  - **평가:** IRIS 적색 판정(WCAG 2.0식)과 R 색 경로가 갈리는 사례를 비교한다.

### D2. Parra 외 (2005) — 색 변조만 줄인 필터 [초록]
*Neurology* 64:787–791

- **무엇을 했나:** 25명에게 포켓몬 장면 원본과 색 변조만 줄인 필터본을 50 Hz·100 Hz TV로 보여 줌.
- **핵심 결과:** 전신성 PPR 시행 비율 50 Hz 56.5% → 8.7%, 100 Hz 41.3% → 4.3%.

- **LUMI에서 할 수 있는 것:** **국소 보정의 방향성 근거**(전체를 흐리지 않고 문제 성분만 줄인다). R 색 경로의 **실영상 시험 사례**(원본 대비 필터본 위험비 약 0.15)로 쓴다.

### E1. Jordan & Vanderheiden (2024) — 국제 PSE 지침 격차 분석 [원문]

- **무엇을 했나:** ITU·Ofcom·WCAG·일본·ISO 지침의 근거를 추적하고 격차를 분석, 새 정의(trace24) 제안.
- **핵심 결과:** 지침은 1990년대 CRT 시절 요인별 실험을 독립 곱 모델로 합친 것. "화면 25%"는 기기에 따라 위험한 사람의 39–57%를 남김. 334 ms 간격, 일본 5회/초, 적색 공식, 연장 깜빡임, 전이 지속에는 "PSE 특이적 자료가 없다." EA IRIS와 Apple VFR은 어떤 표준도 엄격히 따르지 않음. 현대 디스플레이 적색(630 nm)은 CRT(625·704 nm)와 다름.

- **LUMI에서 할 수 있는 것:** 데이터 규약에서 IRIS 결과를 "정답"이 아니라 "IRIS 기본 설정 판정"으로 유지(이미 반영). R의 표시 장치·시청 기하 가정을 이 논문의 trace24 정의(sRGB 상대 휘도, BT.1886 200 cd/m²)에 맞춘다.

- **LUMI에서 할 수 있는 것:** G1과 같은 결론. 다양성 확보 방법(잠재 변수 설계)을 G v2 설계 때 참고한다.

### G3. BSRGAN (ICCV 2021)·Real-ESRGAN (ICCVW 2021) — 무작위화한 수작업 열화 [초록]
- **핵심:** 학습된 GAN 열화 대신 흐림·축소·잡음을 무작위로 섞는 수작업 열화로 학습. Real-ESRGAN은 "순수 합성 데이터만으로" 실제 영상에 일반화. 다만 실제 열화 공간 전체를 덮지는 못한다고 저자가 인정.
- **인사이트:** **Oracle을 충분히 무작위화하는 것이 GAN보다 나을 수 있다**(H0의 강한 선행 사례).
- **LUMI에서 할 수 있는 것:** H1 실험에 "더 무작위화한 Oracle" 대조군을 넣는다. G의 가치는 이 대조군을 이길 때만 주장한다.

### G4. BurstDeflicker (NeurIPS 2025) — 깜빡임 제거 데이터셋 [초록]
- **핵심:** 합성 깜빡임만으로 학습하면 **움직임을 깜빡임으로 오인**하는 문제가 있어 실측 데이터를 함께 씀.
- **LUMI에서 할 수 있는 것:** 실제 원본 영상(움직임이 있는)을 확보해야 하는 이유. R·탐지기 평가에 "움직임은 있지만 깜빡임은 없는" 음성 사례를 넣는다.

### G5. FlashGuard (Pendyala, arXiv 2025) [2차, 3자 요약]
- **핵심:** GAN 없이 무작위 파라미터 합성 영상(학습 1,000·시험 200), PEAT로 라벨링하고 같은 PEAT로 조정·평가 → 순환적이라는 비판.
- **LUMI에서 할 수 있는 것:** **반면교사.** 라벨링·학습 신호·평가에 같은 판정기를 쓰지 않는다(R로 학습했으면 IRIS·외부 판정으로 평가).

## H. 종합 — 구성 요소별로 할 수 있는 것

### H1. G (우리 담당, 최우선)
| 할 수 있는 것 | 근거 |
|---|---|
| 전역 잠재 z(클립 단위)와 넓은 수용 영역(다운샘플·U-Net)으로 구조 변경 | E1 붕괴 분석, A2(64차원 잠재 + KL만으로는 결정적) |
| 다양성 손실(mode-seeking 등) 추가 | A2, E1 |
| 손실 = D(자연스러움) + 최소 R(목표 위험) + 다양성 + 보존. Oracle L1은 약하게 또는 끔 | A2(R 단독 시 흐리기·어둡게 속이기), G1(실제 분포 대신 R) |
| R 목표를 "임계값 위·아래"로 줘서 양쪽 사례 생성 | A1 원칙 |
| 곱셈형 출력 `tanh(·)⊗x` 검토 | A2 보정 쪽 교훈 |

### H2. 최소 R (G의 손실, 우선)
| 할 수 있는 것 | 근거 |
|---|---|
| 휘도 깜빡임 주파수 가중 = Jeavons & Harding 연속 곡선 | C1 (1–30 Hz 견고) |
| 색 경로를 별도로, 색 교대 10–15 Hz 가중, 색 쌍별 상대 위험, 빨강 약변조 항 | D1, D3 |
| sRGB 선형화 + 상대 휘도, 200 cd/m² 기준, 시야각 입력 | E1, E2, C4 |
| 시간 누적(시간 상수 약 2–3초) | F1 |
| 패턴 경로는 후순위 | B1–B4 (근거는 있으나 계산 복잡, IRIS 패턴 불안정) |

### H3. Oracle (G의 기준선이자 대조군)
| 할 수 있는 것 | 근거 |
|---|---|
| 깜빡임 주파수를 곡선 전 구간(특히 8–20 Hz)에서 고르게 | C1 |
| 색 쌍 교대·등휘도 교대 유형 추가(파랑↔초록 같은 약한 음성 사례 포함) | D1, D3 |
| 패턴을 c/deg·대비·면적·방향 집중도·운동 유형(진동/반전/흐름) 축으로 재매개변수화 | B1–B3 |
| "더 무작위화한 Oracle"을 H1 대조군으로 | G3 |

### H4. 평가 (순환 방지)
| 할 수 있는 것 | 근거 |
|---|---|
| G 학습은 R로, 평가는 IRIS(휘도·적색)와 E1 다양성 지표로 | E5, G5 |
| R 단위 시험: pse-test-media, IRIS 확인 시험 자극, 문헌 곡선 재현(주파수 곡선, Parra 순위, Binnie 운동 순서) | E4, C1, D1, B3 |
| 실영상 시험 사례: 포켓몬 원본 대 Nomura·Parra 필터본 (영상 확보 가능 시) | F2, D2 |
| R과 IRIS가 갈리는 사례를 의도적으로 수집·보고 | B2, C1, D1 |

### H5. 데이터
| 할 수 있는 것 | 근거 |
|---|---|
| 라이선스가 확인된 **실제 원본 영상** 확보(움직임 포함) | A1(YouTube 2만 개), G4 |
| 원본 단위 분할 유지 | A1 |
| IRIS 라벨 표기 유지("IRIS 기본 설정 판정") | E1, E5 |

### H6. 우선순위 (제안)
1. **최소 R v0** (휘도·색 깜빡임 경로) + 문헌 곡선 재현 단위 시험
2. **G v2** (구조 변경 + D·R·다양성·보존 손실) → **E2 실험**: 다양성 지표, R 목표 달성률, IRIS 일치율
3. Oracle 확장(색 쌍 교대, 깜빡임 주파수 분포) — G의 대조군 강화
4. 실제 원본 영상 확보 (병행)
5. 패턴 R, H1 본실험(하위 탐지·보정 모델은 팀원과 협의)
