# 목표·기준 고정: Kaya 실영상 + FlashGuard 대비 (2026-11-23, 사용자 결정)

> **목표: FlashGuard(arXiv 2507.19692)를 넘는다.** 비교 무대는 Kaya 2025 실제 위험 영상(외부 경고가 붙은 공개 영상)이다.
> 이 문서는 결과를 보기 전에 비교 방법과 '넘었다'의 정의를 고정한다. 바꾸면 §8 에 사후 변경으로 남긴다.

## 1. FlashGuard 가 한 것과 하지 않은 것 (논문 원문 확인, 11-23)

| 항목 | FlashGuard |
|---|---|
| 탐지 | 화면 50×50 '트리거 배열' 노드마다 CIELAB 프레임 간 평균 색 변화(F = dL/dt + √(da/dt² + db/dt²))를 로지스틱 회귀로 판정, 활성 노드를 보간해 영역 |
| 학습 | 합성 10 초 영상 1,000 중 800, 라벨 = PEAT 영상 단위 이진 |
| 탐지 성능 | 자체 합성 test 200: 정확도 80 %, 민감도 86 %, 특이도 74 %, AUC 0.904 |
| 완화 | 검정 오버레이(불투명도 k, '위험 섬광은 휘도 70 % 근처'로 가정) + 최근 15 프레임 평균 색 반투명 오버레이 |
| 완화 성능 | PEAT 위험 200 영상에서 "92 %" (정의 문장이 잔여/감소 중 어느 쪽인지 모호) |
| **하지 않은 것** | 실제 영상 평가 · 적색 전용 처리 · **공간 패턴** · 사용자 평가 · 실행 속도 측정 · 기준선 정량 비교 · 코드 공개 · 데이터 공개(저자 요청 시 제공) |
| 명시 안 된 것 | 해상도·fps·색 변환·노드 표본 방식·회귀 문턱값·보간법·k 모델·오버레이 α·경계 처리 |

## 2. FlashGuard 재현 (공정성 규칙)

- 명시된 것은 그대로, 명시 안 된 것은 **합리적 후보를 여러 개 두고 FlashGuard 에 가장 유리한 설정**을 쓴다(허수아비 비교 금지). 각 선택과 근거를 표로 남긴다.
- PEAT 라벨은 쓸 수 없음(방송 영상 사용 금지·자동화 불가) → 회귀 학습·k 보정의 라벨은 **같은 판정기(팀원 Partial B2)**로 대신하고, 이 대체를 명시한다. 우리 방법도 같은 판정기를 쓰므로 조건이 같다.
- 기존 B4(간이판: ΔE > 20 → 0.6 감광 + EMA)는 'FlashGuard 근사 v0' 로 남기고, 논문 구조를 따른 **v1**(50×50 노드 회귀 + 보간 + k 오버레이 + 15 프레임 평균 오버레이)을 새로 만든다.
- 가능하면 **저자에게 데이터·코드를 요청**해 저자 test 200 에서도 비교한다(외부 연락 — 사용자 확인 후).

## 3. 비교 축과 지표 (Kaya 22, 원래 해상도·fps)

| 축 | 지표 | 판정 도구 |
|---|---|---|
| **안전(1 차)** | 보정 뒤 위험 영상 비율 · 위험 프레임 감소율(= 1 − 보정 뒤 위험 프레임 / 보정 전 위험 프레임, FlashGuard 의 모호한 정의를 명확히) | 팀원 Partial B2(깜빡임 6 라벨·7 라벨) + 우리 판정기 + EA IRIS(독립 구현) |
| **보존(1 차)** | 위험 밖 영역 입력 대비 변경(PSNR·LPIPS) · 전체 변경량 | 입력 대비 |
| 패턴 | 패턴 라벨 영상에서 보정 뒤 패턴 해소 비율 | 팀원 판정기 + 사람 |
| 자연스러움 | 블라인드 쌍 비교(우리 vs FlashGuard, 순서 무작위) 선호율 — 팀원 평가 | 사람 |

## 4. '넘었다'의 정의 (사전 등록)

다음을 **모두** 만족하면 "Kaya 실영상에서 FlashGuard(재현 v1)를 넘었다" 고 쓴다:
1. 깜빡임 6 라벨 안전 비율이 FlashGuard 이상 (같은 판정기 셋 중 최소 둘에서).
2. 위험 밖 보존(LPIPS)이 FlashGuard 보다 좋음 — 짝 Wilcoxon p < 0.05 (n = 22, 효과 크기 함께).
3. FlashGuard 가 다루지 못하는 패턴 영상에서 패턴 해소 비율 > 0.
4. 블라인드 선호율 > 50 % (평가자 3 명 이상, 쌍 22 개).
보조: South 안전 영상 오탐률이 FlashGuard 이하, 처리 속도 실시간(≥ 원본 fps).

## 5. 진행 순서
1. 판정기 v2 기준선(South Partial B2 판정 — 11-23 밤 실행 중) → 패턴 오탐 분석
2. FlashGuard 재현 v1 (+ 저자 요청 메일 초안)
3. 우리 방법: 알고리즘 마스크 + 딥러닝 오탐 게이트 + 물리 보정기 (+ 재판정 최소 강도)
4. Kaya 비교 → 위 기준 판정 → 에이전트 도구화
