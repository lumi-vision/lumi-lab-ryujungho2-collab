## 2. 패턴의 규격 정의 (원문 — `docs/research/pattern_notes/standards_lineage.md`)
ITC 2001 / Ofcom Annex 1 / BT.1702-3 Attachment 1(informative):
1. **명확히 식별되는 줄무늬**, 어느 방향이든 — 평행·방사·곡선·직선, 점(polka dot) 열 포함
2. 밝고 어두운 **쌍이 5 개 초과**
3. 대비: 어두운 막대 < 160 cd/m² 이고 밝은 막대와 **≥ 20 cd/m²** 차이 (HDR ≥ 160 은 1/17 Michelson)
4. 면적: **정지 > 40 %**, 방향 전환·진동·점멸·반전 > 25 %
5. **한 방향으로 매끄럽게 흐르면 면제**
6. (Harding FPA 해설) 정지 쌍이 **0.5 s 넘게 지속**
— 공간주파수(cpd)·시거리는 규격에 없음(팀원 판의 1–10 cpd 는 Wilkins 문헌 근거의 추가 조건).

## 4. 진행 단계
1. **복사·동일성**: 복사본이 원본과 같은 결과를 내는지 확인(기준점 커밋).
2. **오탐 진단**: 오탐 클립에서 어느 경로(선형 주사·링·스포크·Gabor 대체·FFT 대체)가, 어떤 수치(쌍 수·대비·면적·주기 규칙성)로 패턴을 냈는지 기록. 설정 절제(Gabor/FFT 대체 끄기, 향상 모드 등)로 원인 분리.
3. **적합성 시험 세트 생성** → 현재 판의 경계 오류 측정.
4. **규칙 개선**: '명확히 식별되는 줄무늬'(주기 규칙성·대비 일관성)·면적 산정·지속·흐름 면제를 규격대로. 각 변경은 적합성 세트(재현)·일상 영상(오탐) 둘 다로 검증.
5. 깜빡임·적색: South 놓침 분석(저 fps GIF·작은 영역·휘도 가정) → 규격 모드 / 후보 모드 분리.
6. 판정기 v2 확정 → FlashGuard 재현 → Kaya 비교.
