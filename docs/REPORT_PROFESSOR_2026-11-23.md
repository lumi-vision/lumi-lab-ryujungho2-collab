# 교수님 보고 (2026-11-23) — 복원형 보정 모델 실험과 방향 전환

## 1. 무엇을 하려 했나
기존 대응(감광)은 위험 구간을 어둡게 해 화면 정보를 잃습니다. 그래서 **"위험 자극을 원본 위에 덧씌워진 층으로 보고, 그 층만 걷어내 원본을 복원하자"**는 가설을 세웠습니다.

## 2. 무엇을 가지고 어떻게 돌렸나
- **데이터**: 정답 원본이 있어야 해서 직접 합성했습니다. 팀원 판정기(ITU-R BT.1702 기반 7 라벨)의 위험 7 종을 실제 안전 영상 1,837 개 등 위에 규칙으로 합성 → 3,220 클립. 합성할 때 덧씌운 층(투과율 A, 더한 빛 B)을 정답으로 저장.
- **모델**: CorrNet(0.88M) — 프레임 CNN → 공간·시간 어텐션(8 초 전체) → 층 예측 → 물리 역산 (X − B)/A → 3D 정제. 손실 = 원본 복원 + 층 + 시간 일관성 + 위험 지도 + 안전(미분 가능 판정).
- **검증 설계**: 결과를 보기 전에 비교군 6(무처리·감광·FlashGuard 재구현 등)·절제 4·시드 3·합격 기준을 등록. 60 epoch 학습 16 모델.

## 3. 결과 — 괜찮은 줄 알았는데
- **합성 test(학습에 없는 영화 바탕 140)**: 깜빡임은 98–100 % 안전해졌고, 위험 영역 화질은 팀원 감광보다 크게 좋았습니다(LPIPS 0.41 vs 0.66, p < 1e-8). 학습 곡선도 안정적(손실 0.57 → 0.21).
- **그런데 실제 위험 영상(Kaya 2025, 22 개)을 넣고 다시 판정하고 직접 보니**: 휘도 깜빡임은 국소적으로 잡지만 보정이 부자연스럽고, 줄무늬 패턴은 전혀 못 잡았습니다. 실제 영상에서는 **감광이 가장 나았습니다.**
- 사전 등록 기준(안전 ≥ 95 %)도 합성에서조차 82.5 %로 불합격 — 실패의 95 %가 '정적 공간 패턴'.

**[영상 시연]** `data/correction/kaya_review/` — 왼쪽부터 원본 | 우리 모델 | 감광(B2). ⚠️ 원본 칸은 실제 위험 자극(밝기 낮추고 작은 창으로).

## 4. 왜 — 원인
1. **문제 설정이 실제와 달랐습니다.** 학습은 '덧씌운 층 벗기기'였는데, 실제 깜빡임은 장면 자체(폭발·조명·섬광)라 벗겨낼 원본이 없습니다 → 모델이 없는 내용을 만들어 부자연스러움.
2. **검증을 같은 합성기로만 했습니다.** 손실이 낮다는 건 합성 층을 잘 벗긴다는 뜻이었을 뿐.
3. **패턴은 감광·복원으로 안 사라집니다.** 판정 조건이 밝기 차 ≥ 20 cd/m² 라 흑백 줄무늬는 절반 어둡게 해도 그대로 위험 → 대비 압축이 필요.
4. **판정기 자체의 오탐**: 합성 전 '안전' 영상 2,800 중 1,020(36 %)을 패턴으로 판정.

## 5. 그래서 이렇게 하려 합니다
**탐지와 완화를 분리**합니다. 화면은 신경망이 다시 그리지 않고 원본을 보존하는 물리 필터(깜빡임: 비례 감광 + 시간 평균 / 패턴: 대비 압축)로 고치고, 위치는 판정 알고리즘이 찾고, **딥러닝은 알고리즘의 오탐을 걸러내는 게이트**로 씁니다(실제 영상으로 학습 → 합성-실제 격차 회피). 재판정으로 통과하는 최소 강도를 찾습니다.
최종 목표는 이 판정 → 보정 → 재판정 흐름을 **에이전트 도구(MCP/API)**로 만드는 것입니다.
