## 0. 우리 역할과 목표

| | 내용 |
|---|---|
| 팀 목표 | 영상에서 광과민성 발작(PSE) 위험 영역을 찾아 그 부분만 어둡게 보정 |
| 우리 역할 | **학습 데이터를 만드는 쪽**: 위험 영상을 합성하고, "어디가·언제" 위험한지 정답을 자동으로 붙임. 최종적으로 GAN으로 다양한 데이터를 생성 |
| 팀원 역할 | 실제 영상 데이터와 판별기(rockrovks), 보정(전체 화면 감광 모듈) |
| 왜 합성 데이터인가 | 실제 위험 영상은 드물고(팀원 21개), 라이선스·윤리 문제가 있고, 픽셀 단위 정답이 없음 |
| 왜 판정 기준부터 | 합성 데이터의 정답 = 판정 기준. 기준이 흔들리면 데이터 전체가 흔들리고, GAN은 기준의 빈틈을 공략함 (LESSONS A6) |
