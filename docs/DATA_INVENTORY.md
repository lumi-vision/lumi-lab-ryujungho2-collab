# 데이터 통합 현황

기준: 2026-11-18 로컬 파일·메타데이터 조사. 파일명과 수량만 조사했으며 영상을 재생하지 않았다. 이 문서는 현황 스냅샷이다. 데이터는 복사·이동하지 않았다. 원본, 가공 클립, 모델 산출물은 서로 중복되므로 아래 수치를 합쳐 고유 영상 수로 해석하지 않는다.

## 현재 실제 영상 분할 방침 (2026-11-18, 갱신)

사용자의 후속 결정에 따라 South **2,000개 전부를 학습용**으로 지정하고, Kaya 원본 22개를 외부 평가용으로 둔다. 새로운 목록은 `data/splits/south_all_train_kaya_external_v2/`에 있다. South 별도 검증 분할은 없으므로 독립적인 모델 선택·과적합 확인 방법은 별도로 정해야 하며, Kaya를 반복적으로 조정에 사용하면 최종 외부 평가의 독립성이 떨어진다. 이 목록은 아직 모델 학습에 연결되지 않았다.

### 이전 분할 기록 (더 이상 현재 방침 아님)

이전에는 South를 학습 및 검증으로 나눴다. 아래 v1 목록은 이력용이며 새 학습에 사용하지 않는다. 원본 파일과 목록은 Git 제외 데이터다.

| 분할 | South 위험 라벨 | South 안전 라벨 | Kaya |
|---|---:|---:|---:|
| train | 130 | 1,470 | 0 |
| val | 33 | 367 | 0 |
| 외부 평가 | 0 | 0 | 원본 22개, 라벨 별도 확인 필요 |

고정 시드 20261118, 위험/안전별 약 80:20 분할이다. 동일 SHA-256 파일은 같은 분할에 배치했으며 South 파일 2,000개에서 서로 다른 해시 1,988개를 확인했다. Kaya 원본과 South 사이 완전히 동일한 파일은 발견되지 않았다. **바이트 동일성만 검사했으므로 재인코딩·부분 클립·서로 비슷한 장면의 중복은 미확인**이다. 위험 유형·출처별 층화 및 디코딩 적합성도 별도 검증이 필요하다. 분할 목록만 생성했으며 학습 코드 연결이나 새 학습은 하지 않았다.

주의: 과거 `data/hazcls/real/items.jsonl`에는 Kaya를 `val`로 지정한 기록이 있다. 이 캐시·이전 실험을 새 분할의 근거로 사용하면 안 된다. 과거에 Kaya를 모델 선택에 사용했다면 해당 모델에 대해 Kaya를 최초로 손대지 않은 외부 시험이라고 주장할 수 없다. 새 실험에서는 Kaya로 모델·임계값을 선택하지 않고, 결과를 별도 기록한다. 파일 재생 없이 해시와 경로를 확인했다.

South CSV의 개별 분류는 flash 94, red 12, pattern 67이다. 이 분류는 중복될 수 있으며 위험 163과 단순 합산하면 안 된다. CSV의 safe는 저자 판정이지 무조건 안전하다는 보증이 아니다. Kaya RAR의 크기는 기존 연구 문서의 공식 배포 파일 크기와 일치하지만, 크기만으로 동일성을 확정할 수는 없다. 당시 문서의 '다운로드하지 않음·18~22개 추정'은 이후 로컬 데이터가 생기기 전의 기록이다. 원자료와 제한의 자세한 근거는 [기존 출처 문서](../DATA_SOURCES.md), [Kaya 조사 기록](research/kaya_dataset.md)을 참고한다.

기존 출처 문서에 있는 BBB 640×360, Elephants Dream, Tears of Steel은 과거 확보 기록이다. 이번 조사에서 `data/sources` 및 `data/raw`에는 위 BBB 1080p와 Sintel 외 원본 파일이 보이지 않아 **현재 로컬 보유로 계산하지 않았다**. 다른 경로에 존재하는지는 조사하지 않았다.

### GDR 버전별 샘플 수

`manifest.jsonl` 행 수를 샘플 수로 셌다. 일부 버전의 별도 `.alpha.npz`는 샘플 수에 더하지 않았다. 버전 간 동일 바탕과 실험 조건의 중복이 있다. `val_rule`은 다른 규칙 생성 방식의 검증 자료다.

| 버전 | train | val | val_rule |
|---|---:|---:|---:|
| v1 | 540 | 108 | 108 |
| v2 | 540 | 108 | 108 |
| v3 | 1,020 | 108 | 108 |
| v4 | 1,020 | 108 | 108 |
| v5 | 1,260 | 108 | 108 |
| v6 | 1,740 | 156 | 156 |
| v7 | 2,220 | 204 | 156 |
| v8 | 2,220 | 204 | 156 |

`data/gdr` 전체 크기는 약 336.83 GiB다. 위 표는 보유 현황이지 학습 데이터로 합쳐 사용하라는 뜻이 아니다.

## 확인이 필요한 사항

1. **분할 혼동:** `docs/GDR_VERIFY.md`의 val이 다른 영화라는 설명은 현재 오라클 manifest와 맞지 않는다. 현재 train과 val은 BBB의 서로 다른 구간이고 test는 Sintel이다. 같은 영화 검증 결과를 미지의 영화에 대한 성능으로 제시하지 않는다.
2. **Kaya 라벨:** 22개 최상위 영상과 `out` 결과의 생성 경위, 각 영상의 위험 종류 및 PEAT 보고서 여부, 사용 허가를 확인해야 한다. 파일 목록만으로 실제 위험이나 라벨 품질을 확정하지 않는다.
3. **실제 영상 사용 이력:** `data/hazcls/real`·`real_pair`와 `data/real/eval_rows.jsonl`이 있지만, 폴더명만으로 각 실험의 학습·평가 포함 여부를 확정할 수 없다. 실험별 manifest와 실행 로그를 추적해야 한다.
4. **데이터별 조건:** 실제 영상의 해상도·fps·길이, 바탕 영상의 구간 겹침, 라이선스 원문과 현재 재배포 조건은 이번 파일 수 조사에 포함하지 않았다.
5. **안전한 확인:** 위험 가능성이 있는 원본과 생성물은 재생·미리보기 없이 메타데이터와 판정 결과 위주로 조사한다.
