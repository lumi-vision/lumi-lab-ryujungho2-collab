# LUMI 실험 계획 및 반증 가능한 가설 v0.3

## 0. 전제: 현재는 성능 논문이 아니라 설계·프로토타입

프로토타입은 영상 입력, Oracle 합성, 조건부 G/D 학습 스크립트와 형식 감사기를 포함한다. **표준 기반 PSE 검증기, 위험 영역 정답, 실시간 국소 보정 모델, 검증된 성능 수치는 아직 없다.** 아래 실험은 검증 계획이지 실행 결과가 아니다.

## 1. 최소 가설과 판정 방법

| 가설 | 필요한 대조군 | 1차 성과 지표 | 반증 조건 |
|---|---|---|---|
| H1: Oracle+GAN이 Oracle보다 일반화에 유리 | 동일 탐지기, 동일 학습 예산, Oracle-only vs Oracle+GAN | 외부 독립 데이터의 **이벤트 Recall**, 미탐률 | 개선 없거나 안전 관련 오탐이 과도하게 늘면 기각 |
| H2: 시공간 라벨이 정확도에 도움 | 단순 클래스 라벨 vs 검증된 공간/시간 라벨 | IoU/Dice, 이벤트 지연 | 차이가 없거나 비용 대비 개선이 없으면 기각 |
| H3: 국소 수정은 전역 수정보다 화질 보존 | 동일한 독립 위험 검사 결과를 충족하는 보정끼리 비교 | ROI 외 PSNR/SSIM, 수정 면적 | 표준 검사 충족이 낮거나 왜곡이 더 크면 기각 |
| H4: 시간 모델이 필요한가 | 동일한 공간 인코더 + frame-only/ConvGRU/causal SSM | 시계열 이벤트 Recall + 종단 지연 | 정확도 개선이 없고 지연만 늘면 배제 |

GAN 사용 자체는 기여가 아니라 **측정 가능한 가설**이다. 모델 복잡도가 증가했다는 사실을 개선이라고 쓰지 않는다.

## 2. 실험군 정의

### 데이터 효과 분리

- `D0`: 원본만; 과잉 수정과 정상 보존 기준선.
- `D1`: Oracle-only.
- `D2`: GAN-only (샘플 수를 맞춘 데이터).
- `D3`: Oracle+GAN 혼합.

`D1`과 `D3`의 차이만으로 GAN 이득을 주장하려면 전체 샘플 수와 학습 step을 맞추거나 결과에 그 차이를 명시해야 한다. 가능하면 동량 Oracle 추가 대조군(`D1+more Oracle`)도 둔다. GAN이 단순히 데이터 양의 증가 효과를 대체하는지를 구별하기 위해서다.

### 모델 효과 분리

- `M0`: 명시적 규칙 검사만.
- `M1`: 경량 2D CNN + frame-level 특징.
- `M2`: M1 + causal ConvGRU.
- `M3`: M1 + causal Mamba/SSM (입출력 형상·연산량·지연 조건 명시).
- `M4`: 검증된 후속 보정 Teacher/필터 제어기.

Mamba의 선형 시퀀스 복잡도는 이론적 특성이며 LUMI의 짧은 특징 시퀀스에서 ConvGRU보다 빠르거나 정확하다는 증거가 아니다.

## 3. 데이터 샘플링 원칙

1. **장면 단위 분할:** 같은 장면의 재인코딩본과 GAN 변형본을 서로 다른 split에 넣지 않는다.
2. **모형 선택과 시험 분리:** 개발 중 validation으로 하이퍼파라미터를 정하고 최종 외부 test는 고정한다.
3. **양성/음성/경계 사례:** 위험 조건을 위반한 사례뿐 아니라, 충분히 비슷하지만 판정 기준 아래인 사례도 확보한다.
4. **동시 조건 관리:** 인접 타일의 동시 변화, 패턴 방향, 표시 면적, 움직임 및 fps 변화를 교차시킨다.
5. **표준 버전 관리:** ITU-R BT.1702-3 및 WCAG의 정책별 결과를 별도 컬럼으로 저장한다.

최초 데이터 목표 수량은 실제 확보 가능성 확인 후 확정한다. 독립 원본 수와 장면 다양성이 단순 생성 클립 개수보다 우선이다.

## 4. 평가 지표: 모델 정확도와 영상 적합성 분리

**탐지**: 이벤트 기준 Precision, Recall, FNR, 검출 지연, 오류 유형별 혼동행렬. 픽셀 단위 마스크의 경우 주석 일치도를 먼저 평가한다.  
**보정**: 공식/독립 검사 통과율, 표준 위반 이벤트 수 변화, 수정 면적, 변경되지 않아야 할 영역의 PSNR·SSIM·LPIPS, 시간적 잔상/워핑 오차.  
**시스템**: 종단 p50/p95/p99 처리 지연, FPS, dropped frames, GPU·CPU·메모리 사용량, 색공간/표시 환경.  
**데이터**: 다양성, 중복률, 생성기 유형별 분포 편향, 검사기 판정 불일치율, 보류된 샘플 수.

`L_G` 감소나 `D` 판별 점수 변화만으로 PSE 관련 위험 감소를 입증했다고 볼 수 없다. 정상 영역 화질과 위험 검사 결과가 동시 개선되어야 한다.

## 5. 통계와 재현성

- 각각 고정된 독립 원본 세트에서 평가한다. 기본 실험은 여러 시드(예: 3~5개)로 반복하고 시드별 평균·표준편차를 보고한다.
- 이미지/프레임 단위가 아니라 **원본 영상/장면 단위 부트스트랩**으로 95% 신뢰구간을 구하는 방안을 권장한다. 같은 원본의 파생 프레임은 독립 표본이 아니다.
- 실험 설정에 원본 manifest 버전, 그룹 분할 해시, 환경/드라이버, 모델 체크포인트, 모든 임계값을 기록한다.
- 미탐·과잉 수정 및 예외 상황을 별도 사례로 남긴다. 실패 영상 자체를 공개 게시물에서 자동 재생하지 않는다.

## 6. 최종 논문 작성 시 금지할 주장

- 'LUMI는 PSE 발작을 예방한다' (임상 검증 없음)
- 'GAN으로 만들어서 위험 라벨이 정확하다' (독립 검사 전에는 미검증)
- '16프레임으로 1초 표준 판정을 완료했다' (시간 구간 부족)
- 'ConvGRU보다 Mamba가 더 빠르다' (해당 환경에서 종단 측정 필요)
- 'Barbu GAN을 그대로 재현했다' (현 구현의 목적함수와 레이어 구성이 다름)
