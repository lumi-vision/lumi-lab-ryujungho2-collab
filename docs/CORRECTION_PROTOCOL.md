## 1. 연구 질문

- **RQ1** 합성 짝 데이터(위험 영상 ↔ 원본)로 학습한 보정 모델이, 규칙 보정(전체 감광·팀원 Partial B2 감광)보다 **같은 안전 수준에서 원본을 더 잘 지키는가**.
- **RQ2** 합성 과정을 아는 것(층 정답 X = A·Y + B)이 성능을 올리는가 — 층 손실·물리 역산을 뺀 절제와 비교.
- **RQ3** 긴 시간 맥락(8 s, 인수분해 시간 어텐션)이 필요한가 — 특히 '연장'(5 s 창) 라벨. CNN·짧은 창과 비교.
- **RQ4** 합성으로만 학습한 모델이 실제 위험 영상(Kaya 2025)에서도 판정상 안전을 만드는가(원본 없음 → 재판정과 비참조 지표).

## 3. 방법

### 3.1 제안 (H: 하이브리드)
1. **분석**: 프레임별 CNN(1/8) → 인수분해 트랜스포머(공간 창 어텐션 ↔ 같은 위치 시간 어텐션, 192 프레임 전체) → A·B·위험 지도 예측.
   - 근거: 지도를 먼저 추정하고 그것으로 복원을 조건화 — VDFP(arXiv 2605.21079) **[원문]**. 인수분해 시공간 어텐션 — LPM(arXiv 2607.13460) **[간접: 초록만]**. 긴 창이 필요한 이유 = 연장 기준 5 s 창(EA IRIS, 팀원 config) **[원문]**.
2. **물리 역산**: A ≥ 0.05 에서 Y = (X − B)/A. 근거: 열화를 O = G + F 로 두고 F 를 다룸 — BlazeBVD(arXiv 2403.06243), Lei 외 CVPR 2023 **[원문]**; 우리는 합성식을 알므로 아핀 층으로 일반화 **[선택]**.
3. **정보 없음 채우기**: A < 0.05 는 시간 이웃(깜빡이지 않은 프레임)에서 — 장기 기준(아틀라스) 발상 Lei 외 2023, 흐름으로 이웃 질감 가져오기 BlazeBVD **[원문]**.
4. **정제**: 2프레임 반복 구조, 출력 = 입력 + 잔차 — RMFAT(arXiv 2508.11409) **[원문]**.

### 3.4 절제 (H 에서 하나씩 뺌)
H−layer(층 손실 없음, 영상만 정답) · H−phys(역산 없이 잔차 직접 예측) · H−attn(시간 어텐션 → 3D CNN, 창 1 s) · H−safe(안전 손실 없음) · H−fill(정보 없음 채우기 없음) · 데이터: 투명도 분포를 불투명으로만 학습.

## 5. 1차 비교와 통계 (미리 정함)

- **1차 결과**: 합성 test 에서 (a) Partial B2 안전 비율, (b) 안전해진 클립의 위험 영역 LPIPS.
- H 대 B2(팀원 감광), H 대 E1: (a) McNemar, (b) 짝 Wilcoxon 부호 순위. 유의수준 0.05, 두 비교 Holm 보정.
- 학습 모델은 시드 3개(0·1·2) → 평균 ± 표준편차. 하이퍼파라미터는 val 로만 정하고 test 는 마지막에 한 번.
- 실제(Kaya 22)는 기술 통계만(표본이 작다).

### 5.1 실사용 합격 기준 (사전 등록 2026-11-22 17시, 사용자 승인)

시점: val 의 복원 PSNR 곡선은 본 뒤, **안전 결과·test·Kaya 결과는 하나도 보기 전**. 기준 숫자는 제안값이며 결과를 보고 바꾸지 않는다(바꾸면 §8 에 '사후' 로 기록하고 원래 기준의 판정도 함께 보고).

대상: **H 60 epoch 판(h_s0_e60·h_s1_e60·h_s2_e60)**. 비율은 시드 3개 평균으로 내고, A1·A2 는 시드마다 각각도 만족해야 한다. 30 epoch 판은 같은 기준으로 판정만 함께 보고.

| # | 기준 | 합격선 | 측정 |
|---|---|---|---|
| **A1** | 안전(모델 단독) | 위험 클립 중 보정 뒤 Partial B2 안전 비율 **합성 test ≥ 95 %**, **Kaya ≥ 90 %** | §4 안전 지표 (`safe_team`) |
| **A2** | 새 위험을 만들지 않음 | 보정 뒤 라벨 중 입력에 없던 라벨이 생긴 클립 **0 개** (test·Kaya) | test: `left_labels − labels_before`, Kaya: 보정 뒤 라벨 − 보정 전 라벨 |
| A3 | 안전 입력은 그대로 | (흐름) 판정기가 위험 없음이라 한 입력은 **출력 = 입력(프레임 동일)**. (모델 단독, 참고) test 원본(`.clean.mp4`)을 넣었을 때 입력 대비 PSNR 을 보고 | 흐름 단위 시험 + 추가 측정(코드는 결과 보기 전에 추가) |
| A4 | 위험 밖 보존 | 위험 밖 영역 PSNR(원본 대비) **≥ 45 dB** (mp4 압축 바닥 46–50 dB) | §4 충실도 '위험 밖' |
| **A5** | 감광보다 나음 | 안전해진 클립의 위험 영역 LPIPS 가 B2(팀원 감광)보다 **유의하게 낮고**(짝 Wilcoxon, Holm 후 p < 0.05), 안전 비율은 B2 보다 유의하게 낮지 않음(McNemar) | §5 1차 비교 그대로 |
| A6 | 시간 안정 | 워핑 오차 비율(원본 = 1) **≤ 1.1** (test) | §4 시간 |
| A7 | 실제 일반화 | Kaya 안전 비율이 test 보다 **10 %p 이상 낮지 않음** | A1 두 값의 차 |
| A8 | 속도 | 판정 → 보정 → 재판정 전체가 **1080p 60 초 영상을 이 PC GPU(16 GB)에서 60 초 이내** | 흐름을 만든 뒤 측정 |

판정 규칙: **A1·A2·A5 를 모두 넘으면** "판정 기준(Partial B2) 상 실사용 가능" 이라고 쓴다(임상적 안전 주장은 하지 않음, §6). 나머지는 함께 보고하고, 못 넘은 항목은 한계로 적는다. 흐름(판정 → 보정 → 재판정 → 실패 시 감광 대비책)의 최종 안전 100 % 는 구조적 보장이므로 모델 성능 주장에 쓰지 않는다.

## 6. 알려진 위협

- 정답 라벨이 팀원 판별기 하나(Partial B2) — 깨끗한 BBB 에서도 '정적 공간 패턴' 을 냄(checks/hazard7/d3_val.md: 바탕 81/112). 무늬 라벨은 '새로 생긴 라벨'만 쓰고, 우리 판정기로 교차 확인.
- 합성 ↔ 실제 차이: checks/hazard7/real_vs_synth_d5.md 로 지표 비교를 계속 기록.
- 24 fps 라 12 Hz 넘는 깜빡임은 없음. 60 fps 트랙은 후속.
- 사람 대상 검증(실제 광과민성 환자) 없음 — 판정 기준 충족만 주장한다.
