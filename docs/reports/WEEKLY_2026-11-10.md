## 1. 데이터셋의 중요성

**목표.** 영상에서 광과민성 발작(PSE) 위험 영역을 찾아 **그 부분만** 보정하는 딥러닝 모델(보정 담당 팀원)을 학습시킬 데이터셋을 만든다.

1. **공개 데이터가 사실상 없다.**
   - 동료심사를 거친 딥러닝 PSE 검출기와 공개 벤치마크를 찾지 못했다. FlashGuard(Pendyala 2025, arXiv:2507.19692)도 "공개 저장소가 없다"고 명시한다 (원문).
   - 공개 후보는 둘뿐이다.
     - South 2021(CHI): 위험 163 / 안전 1,837, 소셜미디어 GIF
     - Kaya 2025(SIViP): 약 18~22개, 추정
   - 두 데이터셋 모두 **사람이 붙인 라벨이 아니라 다른 검출기의 판정**이고, 라이선스가 명시되어 있지 않다.
2. **보정 모델은 쌍 데이터가 필요한데, 실제 영상으로는 만들 수 없다.**
   - 위험 영상과 그것을 원본 훼손 없이 고친 정답이 짝으로 있어야 한다.
   - 실제 영상은 원래 장면과 위험 성분을 분리할 수 없다.
   - 합성은 넣은 빛을 픽셀마다 알고 있으므로 정답을 정확히 계산할 수 있다.
     - **A 라벨(탐지 정답)**: 전이한 픽셀
     - **B 정답(보정 정답)**: 판정이 안전이 되는 최소 감쇠
3. **데이터의 정답은 곧 판정 기준이다.**
   - 기준이 흔들리면 데이터 전체가 흔들린다. 그래서 판정기를 표준 조항별로 구현하고 외부 시험 자료로 검증했다(§5).
4. **합성의 현실성이 보정 모델 성능의 상한이다.**
   - 합성이 어설프면 모델은 실제 위험이 아니라 "우리 합성의 흔적"을 지우는 법을 배운다.

## 2. 그래서 Barbu의 GAN을 차용하려 함

**Barbu, Banda & Katz (2020)**, "Deep video-to-video transformations for accessibility with an application to photosensitivity", *Pattern Recognition Letters* 137:99–107, doi:10.1016/j.patrec.2019.01.019 (원문). 구현은 Banda (2018), MIT M.Eng. 학위논문 DSpace 1721.1/121622 (원문)이다.

| Barbu의 구조 | 우리가 가져온 것 | 우리가 바꾼 것 |
|---|---|---|
| 지식 기반 생성기가 깨끗한 영상에 위험 기준 **위·아래** 자극을 넣음 (§3.1.1) | 규칙 기반 합성기(오라클) + 경계 근처 샘플 | 판정 기준을 ITU-R BT.1702-3 조항별로 구현(25% 면적, cd/m² 단위). Banda 구현에는 면적 조건이 없고 "20"이 화소값 차이임 (원문 p.42–44) |
| Forward(위험 생성) / Inverse(보정) 분리 | Forward = 우리(데이터 생성), Inverse = 보정 팀원 | Inverse 학습용 **쌍 정답(A·B)** 을 자동으로 만든다 |
| 미분 가능 탐지기를 손실로 사용 (§3.1.2) | 미분 가능 판정기(soft judge)를 GAN 손실로 | 생성 공간을 **linear RGB에서 빛을 더하는 1채널 Δ**로 제한해, 마스크 밖은 구조적으로 원본 그대로 |

**주의 (선행연구 확인 결과).** "판정기를 손실로 쓰는 GAN"은 Barbu 논문 §3.1.2에 이미 구상으로 나온다. 우리는 이것을 새로움으로 주장하지 않는다.
- 학위논문에서는 Forward에 구현되지 않았다(Forward 목표는 수작업 생성기 출력, §4.2.8).
- Inverse 손실에서는 "flashing regions을 흐리게 지우는 지름길" 때문에 쓰이지 않았다(p.44, p.57).

우리의 기여로 내세울 수 있는 것은 다음 셋이다.
- 표준 조항별 판정의 미분 가능 구현
- 붕괴와 지름길의 정량 측정
- 검출·보정 학습용 데이터라는 응용

## 3. 당면한 문제

| # | 문제 | 실측 | 기록 |
|---|---|---|---|
| P1 | **GAN이 오라클의 평균판으로 붕괴.** Barbu처럼 오라클 결과를 정답(L1)으로 따라 하게 했더니, z를 바꿔도 출력이 같았다 | 세기 표준편차 0.0004 (이상적이면 약 0.2). 오차 0.18~0.19가 "상수 하나로 맞힐 때"의 이론값 0.175와 같았다 (E1, RTX 5080) | LESSONS A1 |
| P2 | **GAN이 판정 규칙의 빈틈을 공략.** 규칙을 목표로 바꾸자, 규칙상 위험하지만 실제론 아닌 출력이 가능해졌다 | 소프트 판정기 v0가 반대 위상 깜빡임을 2번으로 세어 2 Hz 안전 영상이 8.8(위험 목표 충족) | LESSONS A6 |
| P3 | **판정기가 정확해질수록 다양성이 무너짐** | 판정기만 고치면 z 주파수 표준편차 0.38 → **0.06 Hz** (예비) | GAN.md §9 |
| P4 | **판정 기준 자체가 모호하거나 틀림** | ① 두 프레임에 나뉜 변화를 2번으로 세어 1.88회/초를 4.0회로 오판 (A5) ② 줄무늬 1~10 cpd가 출처 없이 쓰이고 있었음 (A9) ③ 외부 정답 파일(pse-test-media JSON)이 같은 세트의 목록 CSV와 16개 모순 (A13) ④ 팀원 판별기가 실제 장면의 휘도·적색 깜빡임을 놓침 (A12) | LESSONS |
| P5 | **움직임과 깜빡임의 구분.** 한 방향으로 흐르는 줄무늬가 픽셀 단위로는 초당 15번 깜빡임으로 측정됨 | 시연 영상 v08 | ANALYSIS.md |
| P6 | **현실성 신호가 없음.** 지금 GAN 손실은 판정기(조절)와 다양성뿐이고, "진짜처럼"을 가르치는 신호가 없다. 사각형 마스크만 쓰면 "가운데 네모 = 위험"이라는 지름길이 생긴다 | 생성 스윕이 사각형만 씀 | PLAN 4판 §2 |
| P7 | **합성 → 실제 전이를 모름.** 합성으로 학습한 모델이 합성하지 않은 실제 위험 영상에서 통하는지 | 미실험 | PLAN 4판 §4 |

## 4. 논문에서 답을 찾음

| 문제 | 문헌의 답 | 적용 결과 |
|---|---|---|
| P1 평균 붕괴 | **pix2pix** (Isola 외 2017, CVPR): "Euclidean distance is minimized by averaging all plausible outputs", "the generator simply learned to ignore the noise" (원문). **Mathieu, Couprie, LeCun 2016** (ICLR): 영상에서 MSE를 쓰면 흐릿한 평균 예측 (초록). Banda 2018도 "very deterministic" (원문 p.45) | 새로운 발견이 아니라 알려진 현상의 정량 재현으로 위치를 정했다. 오라클 재구성 손실을 없애고 **판정 규칙을 목표로** 바꿨다 → 목표 판정 조절 91~99% (E2) |
| P2 빈틈 공략 | Banda 2018: "the generator would simply learn to fool the oracle with low luminance images or garbage" (원문 p.42). 같은 현상이 이미 보고되어 있다 | 판정기를 먼저 엄밀하게 만들었다(설계 결정 D1~D4, 판정기 v1에서 두 방향 동시 = 1번). 소프트↔하드 판정 일치 97% → **100%** (예비) |
| P3 다양성 | **DSGAN** (Yang 외 2019, ICLR), **MSGAN** (Mao 외 2019, CVPR): 잠재코드 거리 대비 출력 거리를 정규화하는 다양성 손실 (초록) | 다양성 손실을 빛의 **시간 스펙트럼**에 걸었다. λ_div 0.5에서 위험 목표 100%, 근처 안전 98%, z 주파수 표준편차 **1.92 Hz** 회복 (예비, 학습 안 한 G는 2.87) |
| 미분 가능 판정기 근사 | **STLCG** (Leung 외 2020, WAFR): 시간 논리 규칙을 역전파 가능하게. **Smooth Operator** (Pant 외 2017, CCTA): max/min 매끄러운 근사의 오차 상한. **Zhong 외 2022**: 미분 가능 규칙으로 diffusion 유도 (초록) | "1초에 3회 초과"는 시간 논리 형태의 조건이다. soft judge의 방법론적 근거로 쓴다. 근사 오차(log-sum-exp +0.8 과대 추정)를 찾아 고쳤다 |
| P5 움직임 | **ITU-R BT.1702-3 부속서 / Ofcom / ITC 2001**: 매끄럽게 한 방향으로 흐르는 패턴은 제외 (원문). **Binnie, Findlay & Wilkins 1985**: 흐름 PPR 0~0.04, 정지 0.38, 진동 0.97 (원문). Harding FPA도 흐름·카메라 이동 제외 (매뉴얼). 움직임 분류에는 **Adelson & Bergen 1985** 운동 에너지 | 정지/반전/흐름 3분류. 흐름은 줄무늬와 휘도 판정에서 모두 제외(결정 A, 재검토 예정) |
| P6·P7 현실성 | Barbu §3.1.1의 위·아래 경계 샘플. FlashGuard(규칙 도구 라벨 + 합성 데이터). 합성→실제 전이 선례 (원문): **FlowNet** (Dosovitskiy 외 2015, ICCV, doi:10.1109/ICCV.2015.316) "networks trained on this unrealistic data still generalize very well to existing datasets such as Sintel and KITTI" — 단, Sintel 자체가 렌더링 영상이고 최고 성능은 미세조정 후. **도메인 무작위화** (Tobin 외 2017, IROS, doi:10.1109/IROS.2017.8202133) 비현실적 무작위 질감의 시뮬레이터 데이터만으로 실제 물체 위치 1.5 cm 정확도, 잡기 38/40 | 방향: 무작위화로 다양성 확보 + 판별자 2개(§6), 실제 데이터 재판정과 분할 |

## 6. 아직 해결되지 않은 문제

**GAN·데이터**
1. **현실성 신호 부재**: 판별자 2개를 추가할 계획이다. 아직 설계 전이다.
   - 합성 결과 전체 대 실제 안전 영상: 데이터가 많다
   - 넣은 섬광 성분 대 실제 위험 영상의 보정용 몫: 데이터가 적어 섬광 성분만 비교한다
2. **합성 → 실제 전이 미검증 (H1)**: 합성만으로 학습한 작은 탐지 모델을 실제 위험 영상(시험용 분할)에서 판정기 기준으로 평가해야 한다. 이 전에는 GAN의 효과를 주장하지 않는다.
3. **GAN 본 학습 미실행**: 지금까지는 노트북 CPU 예비 실험(64×36, 500스텝, 시드 1개)뿐이다. RTX 5080에서 128×72 이상, 시드 3개로 반복해야 한다. v0→v1의 효과는 원인 분리를 한 번만 했다.
4. **GAN은 휘도만 생성**: 적색·줄무늬 생성은 규칙 합성기에만 있다.
5. **마스크 다양성**: 흩어진 영역, 반대 위상, 장면 따라가기, 부드러운 경계, 움직이는 영역이 아직 없다.
6. **B 정답의 정의**: 여유 폭(25%에 붙일지, 20%를 목표로 할지), 줄이는 방식(전체 고르게 / 일부 영역), 훼손 측정 방법. 표준에 없는 값이라 구현 선택으로 정하고 밝혀야 한다.

**판정 기준**

7. **움직이는 위험의 정의**: 표준에 움직임 보정 기준이 없다(Jordan 2024). 흐름 제외(결정 A)는 우리의 확장 해석이다. 실험 근거도 2.5~10°/s까지만 있다. **반대 근거도 새로 확인했다**: Harding 외 2005 EFA 합의문 본문은 TV 맥락에서 "drifting patterns have risks similar to those that are stationary"라고 쓰고, 패턴 지침에서 "한 방향으로 매끄럽게 흐르는" 패턴을 정지 패턴과 같은 범주로 둔다. 이는 Binnie 1985(흐름이 가장 덜 위험)와 강조점이 달라서, 결정 A를 재검토할 때 함께 따져야 한다.
8. **휘도 불일치 유형 A·B**: 작은 두 단계 변화의 누적, 서로 다른 시점의 두 영역을 이어서 세는 문제. 규칙을 바꾸면 모든 라벨이 바뀌므로 결정이 필요하다.
9. **실제 배경에서 줄무늬 면적 과대 측정**: 50% → 58%, 30% → 39%.
10. **"25%의 기준"**: ITU는 화면 비율, WCAG와 Fisher 2026은 시야 기준이고, Fisher 2026은 시야 크기를 정의하지 않는다. 지금은 ITU 화면 비율로 구현했다.
11. **체커보드·동심원·방사·나선 패턴**: 판정도 합성도 없다.

**데이터·운영**

12. **실제 데이터 재판정**: South·Kaya를 우리 판정기로 다시 판정해 "실제 위험 특징 분포"를 만들어야 한다. 원래 라벨이 사람 판단이 아니라는 점을 함께 적는다.
13. **판정 속도**: 2초 영상당 30~60초(팀원 판별기 0.3~0.7초). 대량 생성과 재판정 전에 GPU로 옮겨야 한다.
14. **외부 기대값 모순 보고**: pse-test-media에 이슈로 올릴지 결정해야 한다.
15. **팀원 협의**: 보정 팀원의 입력 형식과 모델 구조, 실제 데이터 팀원과의 분할 합의.
