# 보정 모델(CorrNet) 1 차 — 전 과정과 실패 기록 (2026-11-19 ~ 11-23)

> 결론: **"위험을 덧씌워진 층으로 보고 걷어내 복원한다"는 가설은 실제 영상에서 성립하지 않았다.**
> 합성 test 에서 화질 지표는 감광보다 크게 좋았지만(LPIPS 0.41 vs 0.66), 실제 위험 영상(Kaya)을 사람이 보니 보정이 부자연스럽고, 패턴은 전혀 다루지 못했으며, 실제 영상에서는 감광(B2)이 가장 낫다고 판단했다(사용자 육안 확인, 11-23 21:50).
> 기준·변경 이력은 `docs/CORRECTION_PROTOCOL.md`, 합성 test 수치는 `checks/correction/RESULTS_test_2026-11-23.md`.

## 1. 무엇을 했나 (순서대로)

| 날짜 | 단계 | 내용 |
|---|---|---|
| 11-19~20 | 합성기 hazard7 | 팀원 Partial B2 판정표의 7 종(휘도 플래시·교집합·장면 전환·적색 플래시·휘도 연장·적색 연장·정적 공간 패턴)을 규칙으로 합성. 바탕 = South 안전 영상 1,837·영화·그래픽. 색은 RGB 가 아니라 휘도(cd/m²)·적색 정도로. 마스크는 고정·이동·추적·점광원·원근. 투명도 0.35~1 |
| 11-20 | 정답 층 | 합성을 아핀 층 `X_lin = A·Y_lin + B` 로 기록(A = 원본 투과율, B = 더한 빛) → '복원' 의 정답이 생김 |
| 11-20 | 데이터 big1 | train 2,800 · val 280 · test 140(Sintel). 팀원 판정기로 다시 판정해 라벨. 18.3 GB, 드라이브 공유본 정리 |
| 11-20 | 설계 | 2025–26 선행연구(VDFP, BlazeBVD, Lei 아틀라스, BurstDeflicker, RMFAT, LPM 등) 조사 → 하이브리드 CorrNet H: 프레임 CNN → 인수분해 시공간 어텐션(8 s 전체) → A·B 예측 → 물리 역산 `(X−B)/A` → (2+1)D 정제. 0.88M 매개변수 |

| 11-22 | 합격 기준 | 실사용 기준 A1–A8 사전 등록(안전 ≥ 95 %, 새 위험 0, 감광보다 나음 등) |
| 11-23 | 평가 | 합성 test 140 × 22 방법, Kaya 실영상 22, 육안 확인 |

## 2. 결과

- **합성 test**(Sintel 바탕, 학습에 없음): 깜빡임 6 라벨 안전 98–100 %, 화질은 모든 감광보다 좋음 — 그러나 '정적 공간 패턴' 때문에 7 라벨 안전 82.5 % → **A1·A2 불합격, A5 합격**.
- **Kaya 실영상**(진행 중, 7/22 시점): 휘도 플래시는 7 개 중 3 개에서만 사라짐. 패턴은 거의 모두 남음.
- **육안(사용자)**: "휘도 같은 건 국소적으로 잘 잡긴 하는데 보정이 오히려 부자연스럽다. 패턴은 아예 못 잡는다. 감광 방식이 제일 낫겠다."

## 3. 왜 손실은 좋았는데 실제는 안 됐나 (원인 분석)

| # | 원인 | 근거 | 등급 |
|---|---|---|---|
| 1 | **문제 설정이 실제와 다름**: 학습은 '깨끗한 원본 위에 덧씌운 층'을 벗기는 문제였다. 실제 위험 영상의 깜빡임은 대개 **장면 자체**(폭발·조명·섬광·컷)라 벗겨낼 '아래 원본' 이 없다 → 복원 목표가 정의되지 않고, 모델은 배운 '층 벗기기'를 적용해 없는 내용을 만들어 낸다(부자연스러움) | 육안 소견, Kaya 에서 플래시 제거율 3/7 vs 합성 98 %+ | 분석(가설) |
| 2 | **손실·검증이 같은 합성 분포에서만 잼**: val·test 모두 같은 합성기로 만들었다. 낮은 손실은 '합성 층을 잘 벗긴다' 는 뜻일 뿐 실제 영상의 자연스러움과 무관 | test 는 바탕만 다를 뿐 위험은 같은 합성기 | 확인 |
| 3 | **지표가 자연스러움을 재지 못함**: PSNR·LPIPS 는 '정답 원본과의 거리'. 실제에는 정답이 없고, 합성에서 좋은 거리가 사람이 보는 자연스러움을 보장하지 않음 | 프로토콜 §4 에 이미 경고("LPIPS 는 자연스러움이 아니다") | 원문(우리 문서) |
| 4 | **저해상도 보정량을 화면 전체에 키워 더함**: 384×216 에서 계산한 잔차를 키워 전체에 더해 위험 밖도 조금씩 바뀜(위험 밖 PSNR 37 dB vs 원본 압축 48 dB) | test A4 | 확인 |
| 5 | **패턴은 덧씌움이 아님**: 실제 '정적 공간 패턴'은 블라인드·울타리·글자 같은 장면 무늬다. 모델은 덧씌운 줄무늬만 배웠고, 장면 무늬를 지우는 것은 내용 훼손이다. 또 판정기는 깨끗한 바탕에서도 패턴을 냄(오탐) | 합성 test 실패 38/40 건이 패턴, `d3_val.md` 바탕 81/112 | 확인 |
| 6 | 24 fps·768×432 만 학습, 실제는 8~120 fps·여러 비율 | 데이터 명세 | 확인(영향 크기 미확인) |

## 4. 배운 것 (논문·다음 설계에 쓸 것)

1. **합성으로 정답을 만들 수 있는 문제로 바꾸면, 실제 문제와 달라질 수 있다.** '복원'은 정답이 있어 학습하기 좋았지만, 실제 위험 영상에는 복원할 원본이 없다.
2. **실제 영상에서 판단하는 지표를 처음부터 1 차로 둬야 한다.** 합성 검증 손실은 개발용일 뿐. 실제 영상에서 '재판정 안전 + 입력 대비 변경량 + 사람 평가' 가 1 차여야 했다.
3. **조기 종료·학습량이 비교를 오염시킨다**(30 epoch 결론이 60 epoch 에서 뒤집힘 — 시간 어텐션·층 손실 효과). 비교는 같은 학습량에서.
4. **절제에서 의미 있던 것은 안전 손실뿐**(빼면 안전 57/76). 시간 어텐션·물리 역산·층 손실은 test 에서도 시드 편차 안.
5. 실행 공학: 데이터 로더 과다 미리 읽기(~100 GB), WDDM GPU 메모리 넘침(추론 0.8 s → 70 s), 조기 종료 판정의 잡음 — 모두 `CORRECTION_PROTOCOL.md` §8.
