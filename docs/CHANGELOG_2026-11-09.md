| 마스크 밖 바뀐 값 | 0 | 0 | 0 |

해석과 한계:
- v0 은 조절력은 생겼지만 z 를 거의 무시하는 **부분 모드 붕괴**. v1 은 조절력을 유지하며 다양성이 회복.
- v0 → v1 사이에 **두 가지를 동시에 바꿈**(판정기, λ_div) → 어느 쪽 효과인지 분리 불가. 하나씩 바꾼 실험 미실행.
- 시드 1개, 검증 바탕 12개(한 영화). 반복 미실행.
- 질감 보존율이 오라클보다 높은 것은 더한 빛이 적어서(21.8~24.8 vs 오라클 35~80 cd/m²)일 수 있음. 같은 빛의 양에서 비교 미실행.
