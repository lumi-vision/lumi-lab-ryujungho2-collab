# FlashGuard 비교 기준선 설계

대상 원문: [FlashGuard, arXiv:2507.19692](https://arxiv.org/html/2507.19692), 2025년 버전. 이 구현은 연구용 근사이며 원저자의 학습 모델이나 성능을 재현했다고 주장하지 않는다.

## 논문에 명시된 내용

- 10초 합성 영상 1,000개 중 800개를 학습에 사용하고, PEAT의 클립 단위 이진 출력과 연속 프레임의 CIELAB 변화량을 이용해 로지스틱 회귀를 학습한다. 논문의 남은 200개는 같은 합성 방식의 시험 자료다.
- 화면에 균등한 50×50 격자로 개별 위치의 변화를 측정하고 결과를 보간해 보정 영역을 만든다. 밝기 감광과 15프레임 평균 색을 이용한 반투명 오버레이를 제시한다.
- 보고한 시험 수치는 합성 시험의 정확도 80%, 민감도 86%, 특이도 74%이다. PEAT 기준과 데이터 분포에 의존하며 임상적 발작 확률이 아니다.

## 미공개 사항과 이 구현의 가정

훈련된 회귀 계수·절편, 데이터 원본, 전체 전처리·공간 보간·시간 평균·세부 감광 함수와 불투명도는 논문에서 재현에 충분히 명시되지 않는다. PEAT와 동일 판정을 할 것이라고 가정하지 않는다.

`lumi_synth.baselines.flashguard`는 OpenCV의 float BGR→Lab을 사용하고 `(|ΔL*| + sqrt(Δa*²+Δb*²)) × fps`를 가정한 독립 기준선이다. 각 프레임 차이에서 격자를 표본화해 외부 계수·절편으로 점수화하고 최근접 보간한다. 원문의 학습용 영상 평균 특성과 공간별 프레임 점수 간 적용 방식·시간 평활화는 미확정이며, 현재는 즉시 프레임 점수라는 명시적 가정을 사용한다. 원문과 척도가 다를 수 있으므로 PEAT 결과로부터 **학습 분할에서 새로 적합한 계수**가 필요하다. 임의의 계수는 안전 문턱이 아니다. 첫 프레임 마스크는 정보가 없어 0이다.

`mitigate`는 외부 마스크·감광률·오버레이 비율을 받는다. 원 논문의 자동 감광 예측식은 미구현이다. 15프레임 평균은 픽셀별 원본 BGR 평균이라는 가정이며, 결과는 입력 마스크 밖을 바꾸지 않는다. 정적·동적 공간 패턴을 독립적으로 판정하지 않는다. 기존 `measure`, `roi`, 디코더와 데이터 분할 도구는 이후 비교 실험에 재사용할 수 있으나 이 기준선과 정의를 혼동하지 않는다.

## 평가 계획

동일한 고정 데이터·전처리·판정 도구에서 도구별 검출 민감도·특이도·정밀도, FP/FN과 시간·영역 단위 결과를 평가한다. 위험 라벨의 출처를 별도 기록한다. 최종 독립 시험셋은 어떤 학습·모델 선택·문턱값 선택에도 사용하지 않는다. 기존 Sintel과 Kaya는 이전 사용 이력 때문에 독립 시험으로 바로 지정하지 않는다.

보정은 동일 기준으로 보정 전후 판정 수와 잔여 위험을 비교하고, 정답이 존재하는 자료에서만 MAE·PSNR 등 보존을 측정한다. 국소성(영역 밖 변화), 시간 안정성 및 정보 손실도 따로 기록한다. 정답이 없는 실제 위험 영상에서 원본을 자동으로 안전 정답으로 만들지 않는다.

시간은 디코딩·특징 추출·탐지·보정을 분리해 `perf_counter`로 측정하고 준비·예열·반복 횟수, 하드웨어와 영상 사양을 기록한다. 메모리는 동일 프로세스의 최대 RSS/Windows peak working set을 OS 도구로 측정하고 CPU/GPU를 구분한다. 현재 구현은 전체 프레임과 Lab 배열을 메모리에 보유하므로 장시간 스트리밍 성능을 주장하지 않는다.
