## 1. 데이터 — hazard7 합성기와 big1

### 1.1 합성 방식 (`src/lumi_synth/hazard7.py`, `scripts/make_hazard7_dataset.py`)
- **라벨 체계**: 팀원 Partial B2 의 7 종 — 휘도 플래시 · 교집합 · 빠른 장면 전환 · 적색 플래시 · 휘도 연장 · 적색 연장 · 정적 공간 패턴.
- **바탕**: South 2021 안전 영상 1,837(45 %) · Big Buck Bunny(35 %) · 합성 그래픽(20 %). test 는 학습에 없는 **Sintel**.
- **색**: RGB 가 아니라 **휘도(cd/m²)·색상·채도** 또는 **휘도·적색 비율**로 지정(판정 기준이 그 단위라서).
- **마스크**: 고정 · 이동(drift) · 물체 추적(anchored, Farneback) · 점광원(spot) · 여러 곳(multi) · 원근(perspective) · 화면 전체.
- **리듬**: 규칙 · 비대칭 · 몰아치기. 투명도 α 0.35–1(휘도 표본의 80 %가 0.35–0.9).
- **정답 층**: `X_lin = A ⊙ Y_lin + B` — 상수 입력 0 과 188 을 같은 합성에 넣어 A(원본 투과율)·B(더한 빛)를 잼. 1/4 해상도(108×192) float16 저장.
- **의도**: 종류마다 hazard(기준 넘김) / near(기준 바로 아래) 같은 수.

### 1.2 규격과 규모
| 항목 | 값 |
|---|---|
| 영상 | 8 s · 24 fps · 192 프레임 · 768×432 · H.264 crf 12 yuv420p |
| 분할 | train 2,800 · val 280 · test 140 (Sintel) · Kaya 실영상 22(외부 평가만) |
| 라벨 | 저장한 mp4 를 다시 디코드해 팀원 판정기로. 원본만 판정한 라벨을 빼 **합성으로 새로 생긴 라벨**만 사용 |
| 용량 | 약 18.3 GB (드라이브 공유본 18.5 GB zip 11 개) |

### 1.3 적중률 (`checks/hazard7/big1_train.md`) — 그림 `08_data_hits_and_judge_fp.png`
| 종류 | 휘도 플래시 | 교집합 | 장면 전환 | 적색 플래시 | 휘도 연장 | 적색 연장 | 정적 공간 패턴 |
|---|---|---|---|---|---|---|---|
| hazard 적중 | 191/200 | 196/200 | 200/200 | 153/200 | 180/200 | 148/200 | 163/200 |

**판정기 패턴 오탐**: 합성 전 '안전' 바탕만 판정했을 때 **2,800 중 1,020(36 %)에서 정적 공간 패턴**(휘도 플래시는 20). → 판정기 고도화의 1 차 근거.

## 2. 모델 — CorrNet H (`src/lumi_synth/corrnet.py`)

### 2.1 입력·출력
| | 형태 | 설명 |
|---|---|---|
| **입력** X | [B, T, 3, H, W] | 합성(위험) 영상 sRGB 0–1, BGR. 학습 T = 192, 384×216 으로 줄인 뒤 무작위 112×192 자르기·좌우 뒤집기. 검증은 216×384 전체 |
| 출력 Y | [B, T, 3, H, W] | 보정 영상(선형 빛) |
| 출력 A, B | [B, T, 3, H/2, W/2] | 예측 층 |
| 출력 haz | [B, T, 1, H/2, W/2] | 위험 지도 로짓 |
| 출력 lost | [B, T, 1, H, W] | 정보 없음 가중 = σ((0.05 − mean_c A)/0.01) |

원본·마스크는 **입력이 아니라 손실의 정답**이다.

### 2.2 구조 (매개변수 879,594)
```
X (sRGB) ──┬── sRGB→선형 ──┐
           └───────────────┴─ concat 6ch / 프레임
 인코더   e1 Conv3×3 s2 (6→32)  GN8 GELU   1/2  108×192
          e2 Conv3×3 s2 (32→64) GN8 GELU   1/4   54×96
          e3 Conv3×3 s2 (64→96) GN8 GELU   1/8   27×48            76,032
 시공간   FactorizedST × 4 (dim 96, heads 4)                         622,848
            공간 어텐션: 프레임마다 27·48 = 1,296 토큰 (pre-LN, SDPA, MLP×2)
            시간 어텐션: 위치마다 T = 192 토큰 (= 8 s 전체, 학습 위치 임베딩 256)
 디코더   ↑1/4 ⊕ e2 → d2 Conv (160→64) · ↑1/2 ⊕ e1 → d1 Conv (96→48)
          head Conv3×3 (48→15): A = 1.2·σ · B = 0.25·softplus · haz 1 · feat 8   140,463
 물리 역산  Y_phys = clip((X_lin − B̂)/max(Â, 0.05), 0, 1)
           Y0 = (1 − lost)·Y_phys + lost·X_lin
 정제     Refine3D: 입력 [X_lin, Y_phys, Â, B̂, lost, feat] 21ch
          Conv3d 1×3×3 (21→24) → (2+1)D 잔차 블록 × 5 (시간 팽창 1,2,4,8,1 → 시간 수용 ±17 프레임)
          → Conv3d 1×3×3 (24→3, 0 초기화)                                  40,251
 출력      Y = clip(Y0 + 잔차, 0, 1)
```
- 추론: 정제를 48 프레임 조각(앞뒤 18 겹침)으로(메모리). 평가 해상도 768×432 → 384×216 에서 추론 → **잔차를 키워 원래 해상도 입력에 더함**.
- 절제 변형: `use_attn=False` → 시간 어텐션 대신 1D 합성곱(k 5, 팽창 1·2·3, 740,586 매개변수) · `use_phys=False` → 역산 없이 입력에서 잔차.

### 2.3 근거 (선행연구, `docs/CORRECTION_PROTOCOL.md` §3.1)
위험 지도 먼저 → 복원 조건(VDFP 2605.21079) · 인수분해 시공간 어텐션(LPM 2607.13460, 초록만) · O = G + F 열화 모델(BlazeBVD 2403.06243, Lei 외 CVPR 2023)을 아핀으로 일반화 · 잔차 출력(RMFAT 2508.11409).

## 3. 학습 (`scripts/train_correction.py`)

### 3.1 손실 (가중 합)
| 항 | 식 | 가중치 |
|---|---|---|
| 복원 | Charbonnier(Ŷ, Y, ε=1e-3), 선형 빛. A ≥ 0.05 픽셀 가중 1, 정보 없음 0.2 | 1 |
| 층 | ‖Â − A‖₁ + 4‖B̂ − B‖₁ (1/2 해상도) | 1 |
| 시간 | ‖Δₜ Ŷ − Δₜ Y‖₁ (원본의 프레임 간 변화와 맞추기) | 0.5 |
| 위험 지도 | BCE(haz, 팀원 픽셀 위험 가중/255) | 0.2 |
| 안전 | softplus(c_lum − 5) + softplus(c_red − 5), c = 소프트 판정의 1 초 최대 전이 수 | 0.05 |
| LPIPS | AlexNet LPIPS, 무작위 6 프레임 (학습만) | 0.1 |

### 3.2 설정
AdamW(lr 3e-4, wd 1e-4) · ReduceLROnPlateau(×0.5, 인내 2, val 손실) · 기울기 자르기 1.0 · bf16 autocast · 배치 1 · 1 epoch = train 무작위 600 클립 · val 고정 70 클립(화면 전체) · **최종 60 epoch, 조기 종료 없음**, 체크포인트 = val 손실 최저 · RTX(16 GB) 1 장, 실행당 약 5 시간.

### 3.3 실험 목록
| 실행 | 바꾼 것 | 비고 |
|---|---|---|
| H s0·s1·s2 | — (시드 0·1·2) | 제안 |
| abl_noattn | 시간 어텐션 → 1D 합성곱 | 절제 |
| abl_nophys | 물리 역산 제거 | 절제 |
| abl_nolayer | 층 손실 가중 0 | 절제 |
| abl_nosafe | 안전 손실 가중 0 | 절제 |
| cnn_e0 | 어텐션·역산·층·안전 모두 제거 | 단순 CNN 기준선 |
각각 30 epoch 판(계획)과 60 epoch 판(연장) — 총 16 모델.

### 3.4 학습 곡선 — 그림 `01`, `02`, `03`
- H 세 시드: val 손실 0.57 → 0.21, val 복원 PSNR 24 → **29.4–31.0 dB**(60 epoch). **30 epoch 시점은 수렴 전**(epoch 40 이후 계단식 하락).
- val 손실 < 학습 손실: 학습은 자른 조각 + LPIPS 항이 있고, 검증은 화면 전체·LPIPS 없음(정의 차이).
- 60 epoch val 복원 PSNR: H 30.32 ± 0.65 · −어텐션 29.53 · −역산 30.97 · −층 29.30 · −안전 30.81 · E0 28.98 → **절제 차이가 시드 편차 안**(E0 만 1.3 dB 낮음).

## 5. 왜 실패했나 (요약 — 상세는 POSTMORTEM)
1. **문제 설정 불일치**: 학습 = 덧씌운 층 벗기기(정답 있음). 실제 = 장면 자체의 깜빡임(벗길 원본 없음) → 모델이 없는 내용을 만듦.
2. **검증이 같은 합성 분포**: 낮은 손실 ≠ 실제 자연스러움.
3. **패턴은 덧씌움이 아니고, 감광으로도 안 사라짐**: 판정 조건이 밝기 차 ≥ 20 cd/m²(팀원 `config.py`: 1–10 cpd, ≥ 6 쌍, 면적 > 40 %, 0.5 s) → 흑백 줄무늬(≈200 cd/m² 차)는 절반 감광해도 ≈100 cd/m². **대비 압축·공간 저역 통과**가 필요. 게다가 판정기가 안전 바탕의 36 %에서 패턴을 냄.
4. **저해상도 잔차를 전체에 더함** → 위험 밖 화질 저하(37 vs 48 dB).

## 6. 다음 방향 (채택, 11-23)
**탐지와 완화를 분리**: 위치(위험 지도 M_flash, M_pattern)는 판정기·탐지기가, 화면 수정은 원본을 다시 그리지 않는 **물리 필터**(깜빡임: 비례 감광 + 15 프레임 평균 블렌딩 — FlashGuard 원리 / 패턴: 대비 압축 + 저역 통과)가 하고, 재판정으로 통과하는 최소 강도를 찾는다. **먼저 알고리즘 판정기 고도화**(패턴 오탐 36 % 해결) → 물리 보정기 → 실제 영상·사람 평가를 1 차 지표로.
