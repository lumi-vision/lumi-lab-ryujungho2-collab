# LUMI G 발표 메모

## 1분 시연

1. **기존 영상 실험을 먼저 보여준다.** [클립 검증 그림](G_기존_클립_검증.png)은 과거에 저장한 BBB 검증 쌍의 중간 프레임이다. “원본과 G 출력이 짝으로 남아 있어, 무엇이 바뀌었는지 픽셀 단위로 확인할 수 있습니다. 이 예시에서는 전체 48장 중 41장에서 변화가 있었고, 48장을 모두 합쳐 마스크 밖에서 달라진 픽셀은 0개였습니다.”
2. **발표 PC에서 `LUMI_G_Demo.exe`를 연다.** BBB 장면이 먼저 뜬다. “타원은 사용자가 지정한 영역입니다. 위치가 주어지면 학습된 휘도 G가 장면과 마스크를 입력으로 받아 밝기 변화를 계산합니다.” 왼쪽 나무의 다른 위치를 한 번 클릭하고 수치가 바뀌는 것을 보여준다.
3. **‘변경 픽셀 강조’를 켠다.** “초록색은 원본과 G 출력의 RGB 값을 비교했을 때 실제로 바뀐 픽셀입니다. 테두리로 준 허용 영역보다 실제 변경 영역이 작을 수 있습니다.” 내장 예시 첫 화면은 34,573픽셀 중 1,061픽셀이 바뀌었다. 현장 시연이 어려우면 [정지 비교 그림](G_발표용_비교.png)을 사용한다.

## 발표에서 구분할 결과

| 결과 | 근거 | 해석 범위 |
|---|---|---|
| 기존 영상 G의 국소성 | BBB 검증 바탕 0, 기존 48프레임 NPZ 전체에서 원본·출력을 재대조. 재계산한 변경 마스크가 저장본과 모든 위치에서 일치 | 특정 영상 쌍 한 건의 확인 |
| 실시간 발표 데모 | 휘도 G의 실제 가중치, 768×432, 시간 길이 1. 마스크 안팎의 8비트 변화량을 원본과 직접 비교 | 한 장에서의 공간적 반응. 시간축의 점멸 판정은 기존 영상 실험에서만 관찰 |
| 과거 검증에서 위험 목표가 내부 판정 기준에 도달한 횟수 | 휘도 48/48, 적색 28/48, 줄무늬 41/48. 각각 아래에 연결한 체크포인트의 기록 | 종류별 BBB 검증 바탕 12개 × 잠재벡터 4개. 훈련·검증이 같은 작품이므로 새 작품 일반화, 독립 탐지 정확도, 임상 결과는 미평가 |
| 보정 모델에 쓸 수 있는 자료 | 합성 전의 장면, 허용 마스크, 실제 변경 마스크, 합성 후의 장면을 함께 저장 | 합성 전 장면을 복원 참조로 사용할 수 있다. 보정 성능과 실제 위험 영상에서의 복원 품질은 별도 평가가 필요 |

과거 실험표는 [휘도](../checks/gan/w_div2.0_2k_s0.md), [적색](../checks/gan/r4z2_crisp2_div2.0_s0.md), [줄무늬](../checks/gan/s5pat_div2.0_s0.md)에 있다. [작품별 사용 이력](research_data_v1.md)에서 BBB train/val 중복을 확인할 수 있다.

## 실행판 점검 기록

- Windows x64 단일 실행파일에 ONNX 모델, CPU 런타임, 예시 이미지가 포함된다. 이번 PC에서 임시 폴더를 작업 경로로 잡고 기본 창 열기 및 닫기, 자체 점검, PNG 저장을 실행했다. 다른 PC의 실행 정책과 운영체제 호환성은 미확인이다.
- 내장 원본은 Big Buck Bunny의 720번 프레임(0부터 셈)이다. 사용자 파일을 열면 사진은 한 장, 8비트 SDR 영상은 첫 표시 프레임 한 장만 읽는다. 종횡비를 유지하고 여백을 마스크에서 제외한다. Spring WebM에서도 첫 프레임 읽기와 여백 제외를 점검했다. 원본 작품 제공 및 이용 조건은 [Blender Foundation](https://peach.blender.org/)과 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)에 있다.
- 휘도 체크포인트 SHA-256은 `6f61f747e78b92efff2e3922aff084e16c475f6f5d0e7bd7950e097a097b01da`이다. 기존 PyTorch G에서 시간 길이, 조건 및 잠재벡터를 고정해 내보냈다. 두 시험 마스크에서 원본 PyTorch 출력 대비 ONNX 최대 절대 오차는 각각 0.00000034, 0.00000028(0~1 채널 값)이었다.
- 배포 EXE의 자체 점검은 기본 위치와 옮긴 위치에서 각각 1,061개와 587개의 변경 픽셀을 관찰했고, 두 경우 모두 마스크 밖 변경은 0이었다. `--verify <새 폴더>` 옵션으로 해당 실행파일에서 재검사할 수 있다.
- 이번에 실행한 관련 회귀 명령은 `.venv\Scripts\python.exe -m pytest -q tests/test_dataset_timing.py tests/test_research_compare.py`이며 12개가 통과했다.
- EXE SHA-256은 `a4b2a1c9b7a175f86ce0ab4c7f30d75a934df0291a0b17939690bbadfa3a2f94`이다. 발표용 변환과 GUI는 `scripts/presentation/`에 있다. 시간 축에서의 합성 성능 수치는 기존 실험 결과이며 이번 발표판 제작에서 새로 학습한 결과는 없다.
