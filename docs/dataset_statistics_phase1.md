# 데이터 현황 및 시험 통계

2026-11-18 읽기 전용 조사. 상세 출처·집계 방법은 [데이터 통합 현황](DATA_INVENTORY.md)을 따른다. 이 표는 새 스키마에 실제 영상을 일괄 등록하거나 데이터 사용 조건을 확인했다는 뜻이 아니다.

| 대상 | 수량 | 계보·상태 |
|---|---:|---|
| BBB 원본 | 1 작품 | 기존 G train 60개·val 12개 배경 클립의 원본 |
| Sintel 원본 | 1 작품 | 기존 G test 16개 배경 클립의 원본 |
| South | 2,000 파일 | CSV 도구 라벨 위험 163, 안전 1,837. 새 방침은 전량 train, 사용 조건 미확인 |
| Kaya | 원본 22 파일 | 기존 실험에서 16개 val 활용 기록, 6개 test 기록. 독립 최종 시험으로 일괄 간주하지 않음 |
| 기존 oracle manifest | 352 행 | train 240, val 48, test 64; 생성 표본이며 고유 작품 수가 아님 |

소규모 자동화 시험은 단색 프레임 10개로 만든 1개 원본과 그중 4프레임 클립을 사용했다. 원본·클립의 작품은 1개, 역할은 train, 위험 라벨은 미확인이며, 원본 입력 해시와 PTS 매핑을 검증했다. `pytest tests/test_dataset_phase1.py`의 임시 파일은 시험 종료 후 보존하지 않는다. 위험 영상을 생성하거나 재생하지 않았다.
