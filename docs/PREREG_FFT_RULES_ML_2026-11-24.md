# 사전 등록: Temporal FFT · 격자 · 규칙 margin · 학습 가중치 비교 (2026-11-24, 결과 보기 전 작성)

> 계기: 교수님 제안 — "temporal FFT 기반, 크게 네 가지로 분류, 세부는 조사한 조건으로, 알고리즘끼리 가중치는 머신러닝으로".
> 이 문서는 **실험을 돌리기 전에** 커밋한다. 결과를 본 뒤 기준·특징·모델을 바꾸면 그 사실과 이유를 §7 변경 기록에 남기고, 바꾼 결과는 '탐색적'으로만 보고한다.

## 1. 질문과 가설 (주 라벨 = South 사람 라벨 `flash`)
| | 비교 | 가설 | 근거(왜 이렇게 예상하나) |
|---|---|---|---|
| H1 | M2 격자 FFT vs M1 화면 평균 FFT(원문 방식) | 격자가 낫다 | 화면 평균은 국소 깜빡임을 묽힘 — 우리 실험(LESSONS A2), 규격은 면적 25 % 조건으로 국소성을 본다(ITU-R BT.1702-3) |
| H2a | M4 규칙 margin + 격자 FFT (회귀) vs M3 규칙 margin (회귀) | FFT 가 더해 준다 | FFT 는 규칙이 버리는 문턱 아래·주기 정보를 담음 |
| H2b | M4 vs M0 규칙 판정 점수(학습 없음) | 학습 가중치가 더해 준다 | 교수님 제안의 핵심 주장 |
| H3 | M5 (M4 + CorrNet 고정 특징) vs M4 | **차이가 작을 것**(정보 중복) | CorrNet 탐침(checks/probe_detection.md)은 R(2+1)D 와만 비교됨 |

## 2. 데이터
- South 2021(사람 라벨, GIF/짧은 영상) 2,000 중 디코드 가능한 것 전부. 주 라벨 `flash`(양성 94), 보조 라벨 `dangerous`(163).
- `red`(양성 12)는 너무 적어 **검정하지 않음**(기술 통계만). `pattern` 은 사람 라벨이 규격 패턴의 정답이 아님을 확인했으므로(checks/judge, 2026-11-24) **제외**.
- 한계(미리 밝힘): South 사람 라벨은 '규격 위반'이 아니라 '사람이 보기에 깜빡임/위험'이다. 따라서 이 실험은 **사람 판단을 얼마나 따라가는가**를 재며, 규격 판정의 정확도를 재지 않는다(규격 정확도는 적합성 시험·parity 로 이미 별도 검증).

## 3. 특징 (모두 영상 1 개당 고정 길이, 정의는 `scripts/fft_rules_ml.py`)
- **M0 규칙 판정(학습 없음)**: G 의 F1·F2 1 초 최대 깜빡임 수(max) — 연속 점수로 AUC.
- **M1 화면 평균(원문)**: 프레임 평균 휘도 L(t)(cd/m²)의 1 초 창 temporal FFT 진폭 — ≥3 Hz 대역 최대 진폭, 1–3 Hz 대역 최대 진폭, 우세 주파수; 프레임 차 D_t 의 평균·최대; 평균 적색 비율 FFT ≥3 Hz 최대 진폭.
- **M2 격자 FFT**: G 와 같은 격자(가로 32 칸)의 칸 평균 휘도 시계열에 같은 FFT — ≥3 Hz 진폭의 칸·창 최대, 칸 90 백분위, 진폭 ≥ 5·10 cd/m² 인 칸 비율의 창 최대, 1–3 Hz 동일, 우세 주파수; 칸 적색 비율 FFT 동일 요약.
- **M3 규칙 margin**: 픽셀 단위 전이(G F1/F2 와 같은 정의)로 — 1 초 창에서 전이 ≥ 4·≥ 7 인 픽셀 비율의 최대(면적 여유), 면적 5·10·25 % 를 만족하는 최대 전이 수(빈도 여유), G 판정 깜빡임 수, 연장 깜빡임 여부, 적색 동일 + 최대 Δu′v′.
- **M4** = M3 + M2. **M5** = M4 + CorrNet 고정 특징(`data/probe/feats.jsonl` 의 A, 384 차원).

## 4. 모델·평가 (고정)
- 로지스틱 회귀(표준화, C = 1, class_weight = balanced, max_iter 2000) — 탐침 실험과 같은 설정. 하이퍼파라미터 탐색 없음.
- 5 겹 층화 CV × 10 반복(시드 0–9). 영상별 OOF 확률을 반복 평균.
- 지표: ROC AUC. 차이 검정: 영상 단위 **짝지은 층화 부트스트랩 2,000 회**로 ΔAUC 와 95 % 신뢰구간, 한쪽 p.
- **"나아졌다" 판정 기준**: ΔAUC ≥ **0.02** **그리고** 부트스트랩 한쪽 p 를 주 가설 4 개(H1, H2a, H2b, H3)에 **Holm 보정**해 α = 0.05 통과. 둘 중 하나라도 못 넘으면 "개선이 보이지 않음"으로 기록한다(“경향” 같은 표현으로 주장하지 않음).
- 보조 라벨 `dangerous` 결과는 같은 방식으로 표시하되 **탐색적**으로만 쓴다.
- 해석용: M4 를 전체 데이터로 학습한 표준화 계수 상위 항목(어떤 특징이 점수를 끌어올리는지).
